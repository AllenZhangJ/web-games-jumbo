# Arena V2 P5 地图路线研究卡片 Candidate V1

状态：`code-written-not-run`。按“开发优先”要求，本批未运行测试、类型检查、构建、压测或设备验证。

## 目标

地图收藏页的两张地图卡不再只显示“完成了几段”，而是复用既有 Profile 路线证据，直接告诉玩家：

- 当前处于 `初识 / 熟悉 / 熟练 / 掌握 / 路线全通` 哪一阶段；
- 已理解路段数；
- 下一条尚未理解的真实路线段名称及其当前练习次数；
- 下一个 `25% / 50% / 75% / 100%` 里程碑还需多少次有效路线练习。

这使地图熟悉本身成为可读的短期目标，支撑“主要通过武器和地图增加游戏时长”的产品方向。

## 边界

`arena-v2-map-route-research-selection-projection-candidate-v1.ts` 是纯只读投影：

- 精确覆盖正式两张地图，并保持目录顺序；
- 复用 P6 已有路线里程碑计算器，不复制成长算法；
- 按地图 Definition 固定段落顺序读取逐段 Profile 证据，第一条未完成路线段就是卡片上的下一练习目标；
- 只替换卡片已有的“路线理解 X/Y”片段，不新增字段、页面、按钮、奖励或 Profile 写入；
- 保留当前目标、地图人数、路线数量和可用性语义；
- 身份、证据、完成段数或既有文案漂移时，在产生表现副作用前失败关闭。

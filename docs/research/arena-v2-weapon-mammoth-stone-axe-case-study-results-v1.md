# 猛犸石斧逐动作研究结果 V1

## 状态与边界

- 状态：第九轮逐件研究完成，已接入官方证据集和共享案例合同
- 日期：2026-07-28
- 生产影响：不注册默认生产目录，不改变正式玩家存档、正式武器卡或操作合同
- 研究来源：[猛犸石斧官方说明](https://bfo.web.sdo.com/web4/introduce/prop_explanation.asp?id=775)
- 数值边界：距离、覆盖、控制、击退、收招和再次使用时间可以进入后续 Definition 原型；延迟时间、预警时间、墙面反弹和公共危险路径仍必须先经过原型验证

猛犸石斧被选为第六件深研武器，是因为它与已经完成的五件案例形成明显差异：它的核心不是连段、射线、拉位或读招蓄力，而是把“现在提交”与“稍后落点”分开，再利用滚动物体、墙面和公共危险改变地图路线。

## 官方事实拆解

| 动作单元 | 官方输入 | 官方可观察结果 | Arena 学习问题 |
| --- | --- | --- | --- |
| 延迟落斧 | `ZC` | 约 3 秒后落点；命中后先短暂眩晕，再倒地，可追加 | 玩家能否看见落点并在延迟期间改变路线 |
| 地面蓄力 | `ZX-X` | 蓄力对应 3 种攻击方式，前方范围可击倒 | 蓄力时间是否真正改变覆盖和控制，而不是只改外观 |
| 滚动钱币 | `转一圈XC` | 地面物体向前滚动，命中后暴击击飞，对地有效 | 固定方向的滚动物体能否逼迫目标跳跃或侧移 |
| 跑动撞墙 | `跑XC` | 斧柄撞击后重击飞，撞上前方石块后可能弹回追击 | 墙面、边缘和目标初始位置如何改变命中后的路线 |
| 猛犸召唤 | `ZXC` | 猛犸连续冲刺；不躲开时使用者自己也会受伤 | 高回报是否同时制造敌我共同的公共危险 |
| 猛犸肉 | 攻击结束后出现 | 最多可食用三次，每次回复 5HP | 战斗后的恢复物是否会成为新的路线争夺，而非无条件奖励 |

## 逐动作玩家决策与反制

### 1. 延迟落点

这不是“更慢的普通攻击”，而是两条时间轴：按键时刻与危险生效时刻。玩家需要学习的是预测对手路线、看懂落点提示并决定是否继续走原路线。对手的基础反制应只需要移动、跳跃和改变高度，不需要新增防御键。

必须公开的字段是：延迟时间、预警时间、落点覆盖、有效窗口和挥空后的恢复。当前 `ActionDefinition` 只有通用 windup/active/recovery，尚未把“预警”和“危险生效等待”作为独立权威字段，因此不能直接把官方约 3 秒写成正式玩家数值。

### 2. 蓄力地面重击

三种官方攻击方式说明蓄力改变的是招式形态和控制结果。Arena 的最小版本应收敛为最多两档：低档快速保位置，高档扩大覆盖并增加控制；高档必须有更长可读承诺和空放恢复。

### 3. 滚动物体

滚动物体的学习价值在于它会持续占据一条路线。它不应自动追踪目标，否则玩家记住的只是“按键后会命中”；正确的最小原型应固定方向、公开结束时间，并让跳跃、侧移和绕行都能处理它。

### 4. 墙面反弹

跑动撞击的结果不能只用“击退数值”描述。必须同时记录目标是否接触墙面、反弹后的落点、攻击者自身位移和追击窗口。若目标没有碰墙，第二阶段不应自动成立。

### 5. 公共危险与恢复物

猛犸召唤把使用者也放进风险范围，说明大招的价值不是单方面输出。恢复物则把一次攻击结果延伸成新的路线选择：回收会得到收益，但可能重新进入危险位置。Arena 首个版本只应先验证公共危险和资源点的可读性，不直接迁移自伤、治疗和三次使用规则。

## 必须展示的数值轴

| 数值轴 | 状态 | 玩家要知道什么 |
| --- | --- | --- |
| 有效距离 | 后续 Definition | 目标需要离多近才进入可威胁范围 |
| 覆盖宽度 | 后续 Definition | 蓄力重击或落点能封住多宽的路线 |
| 出手/承诺时间 | 后续 Definition | 对手有多少时间离开落点 |
| 延迟时间 | 研究字段 | 从预警到危险真正生效需要多久 |
| 预警时间 | 研究字段 | 玩家看到危险后有多少回应时间 |
| 横向作用 | 后续 Definition | 命中后会把目标推向哪里、推多远 |
| 垂直控制 | 后续 Definition | 是否改变目标落点和墙面关系 |
| 自身位移风险 | 后续 Definition | 攻击者是否会被带离安全面 |
| 收招/再次使用 | 后续 Definition | 空放后多久恢复、多久可以再次尝试 |
| 墙面/支撑面结果 | 研究字段 | 命中是否转化为反弹和追击 |

这组字段说明：猛犸石斧不能只放一张“攻击力/射程”卡。延迟和预警必须在概览中以独立状态显示；在真正接入权威 Definition 前，应显示“待原型验证”，而不是填入看似精确的数字。

## Arena 最小功能版本

- 核心动词：预判落点并改变路线；
- 地面：固定方向重击或滚动物体；
- 蓄力：最多两档，阶段清晰、覆盖和控制不同；
- 地图：至少验证宽平台、窄路、墙面和边缘；
- 反制：移动、跳跃、改变高度、等待恢复；
- 不迁移：MP、三档复杂派生、自伤、治疗物、自动墙面吸附和原作伤害数值。

4. 尚无设备表现、声音/特效和正式武器概览验收；

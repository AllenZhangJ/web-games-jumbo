## 产品目标

玩家从首页进入模式选择后，应在第二次主要点击前直接知道：

1. 当前模式的目标；
2. 参与人数；
3. 全部6个角色、20把武器和2张地图20个路段都只使用方向、跳跃和主攻击；
4. 角色只改变操作手感，不增加格挡、下砸、冲刺、蹲伏或额外按键。

首页继续用既有`next-goal / last-mode / quick-start`说明目标、上次模式和两次主要点击内开局，不重复塞入完整操作说明。模式选择页把既有`character-entry`提升到首屏，既有`record-type`移入同页延后信息；字段数量、页面数量、主动作和两步开局预算不变。

## 单一来源

`arena-product-content`中的`ARENA_V2_THREE_CONCEPT_INPUT_CONTRACT_CANDIDATE_V1`是产品输入合同唯一来源，已经静态闭合：

- 6个角色共享`direction / jump / primary-attack`；
- 20把武器的40个地面/空中动作都只消费主攻击，按住与松开仍属于同一个主攻击概念；
- 2张地图共20个路段只要求方向与跳跃，攻击只用于玩家之间的对抗；
- `slamPressed`强制关闭，格挡、蹲伏、冲刺和下砸均关闭。

`arena-product-presentation`中的`ARENA_V2_CONTROL_LEARNING_COPY_CANDIDATE_V1`只负责把该合同本地化为视觉短句和口语短句，并绑定输入合同内容hash。若未来产品合同不再是精确三概念，或开启格挡、蹲伏、冲刺、下砸，文案模块在发布错误说明前失败关闭，要求重新设计信息合同。

`arena-presentation-runtime`中的共享平台操作映射是实际控制与展示之间的唯一桥接数据：键盘固定使用WASD/方向键移动、空格跳跃、J/E攻击；触控固定显示方向盘、跳跃键、攻击键。蓄力武器继续按住并松开同一个攻击键，不增加新的输入概念。键盘/触控Driver、触控Visual Tokens及操作学习文案只能引用该映射，不得各自维护第二套键位或标签。

## 入口接线

- 固定tick键盘Driver只监听WASD/方向键、空格、J/E，并固定输出`slamPressed=false`。
- 固定tick触控Driver直接构造`simple-three-concept-v1` Mapper；拖动跳跃或主攻击按钮不能生成隐藏第四动作。
- 正式Web候选只在上述键盘/触控Driver之间选择，不接历史通用slam映射。
- 加载页、模式选择页、角色选择页和对应读屏播报消费同一文案合同；Presentation不拥有输入映射，也不从文案反向生成InputFrame。

## 首屏与可访问性

- 模式选择首屏固定为`mode-objective / participant-count / character-entry`。
- `record-type / preparation-entry`保留为同页延后信息。
- 视觉先显示“方向 + 跳跃 + 主攻击”，再显示键盘和触控的实际映射；读屏先播报三概念，再完整播报两种平台操作及蓄力按住松开语义。
- 角色选择页继续说明具体手感差异；不会把6个角色误写成6套按键或技能。

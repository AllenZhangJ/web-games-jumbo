# Arena V2 武器攻击者失位与双人争夺原型结果 V1

## 文档状态

- 状态：已完成第一轮攻击者自身位移、空中上下文和双人同时出招验证；真人可读性、多人拥挤和正式 V2 权威迁移仍待验证
- 日期：2026-07-27
- 目的：验证武器差异是否同时改变“我把对手推到哪里”和“我自己会不会失位”，以及两名玩家同时出招时是否仍能形成可观察结果
- 不代表：最终平衡、最终命中盒、多人网络同步或生产模式已经完成

## 1. 实验合同

入口为 `runArenaV2WeaponContestPrototype()`，位于 `packages/arena-v1-experiment`。实验只在开发/测试工具链运行，使用当前 Arena V1 规则层和轻量物理。

固定条件：

- 使用重锤、引力锁链和冲锋盾三把当前原型武器；
- `self-displacement`：目标静止，记录动作开始时的攻击者自身冲量与 120 tick 后位移；
- `aerial-context`：攻击者从目标上方 1.8 格开始，使用现有空中动作候选，记录实际命中 tick 和垂直位移；
- `mutual-attack`：使用重锤/锁链、锁链/冲锋盾、冲锋盾/重锤三组配对，两名玩家在同一 tick 发起攻击；
- 规则命令仍通过 mutation port 进入轻量物理，不在实验层改写命中或击退；
- 同一 seed、同一输入和同一配置必须得到相同结果。

## 2. 实验结果

### 2.1 攻击者自身位移

| 武器 | 自身冲量 | 120 tick 后横向位移 | 首次命中 |
|---|---:|---:|---:|
| 重锤 | 0.00 | 0.00 | 18 tick |
| 引力锁链 | 0.00 | 0.00 | 12 tick |
| 冲锋盾 | 6.50 | 0.1998 | 5 tick |

这证明“自身位移风险”不是 UI 为了凑满八项数值而添加的描述，而是规则层实际存在的可测量属性。冲锋盾的数值不能只用“命中快”表达，还必须同时显示“自身位置变化”。

### 2.2 空中上下文

三把武器都能在固定的空中初始条件下完成一次有效命中：

| 武器 | 首次命中 | 攻击者横向位移 | 攻击者垂直位移 |
|---|---:|---:|---:|
| 重锤 | 10 tick | 0.05 | 1.80 |
| 引力锁链 | 7 tick | 0.05 | 1.80 |
| 冲锋盾 | 4 tick | 0.05 | 1.80 |

这个实验只验证空中动作确实进入同一规则/物理链路，不把三次命中率当作最终平衡结论。空中动作的概览至少需要显示：

- 空中有效距离或覆盖半径；
- 下落/接触前摇；
- 目标的横向与纵向结果；
- 攻击者落点风险。

这与热血英豪官方指南强调的“跳位、空中转向和不同动作上下文”相吻合，但 Arena 只保留方向 + 跳跃 + 一个攻击输入，不迁移复杂连招或防御系统。[官方新手指南](https://bfo.web.sdo.com/web4/guide/xinjing.asp)

### 2.3 双人同时出招

三组配对中，两名玩家都在 tick 0 成功开始动作；但是较早命中的攻击可能先改变另一名攻击者的位置，使后续动作挥空：

| 配对 | 先命中者 | 另一方结果 | 观察到的规则后果 |
|---|---|---|---|
| 重锤 vs 引力锁链 | 引力锁链，12 tick | 重锤挥空 | 拉位先改变重锤的目标位置 |
| 引力锁链 vs 冲锋盾 | 引力锁链，12 tick | 冲锋盾未命中 | 冲锋盾自身位移后不再处于有效命中关系 |
| 冲锋盾 vs 重锤 | 冲锋盾，5 tick | 重锤挥空 | 冲锋盾先换位，重锤慢前摇失去目标 |

这不是最终平衡结论，但关闭了一个重要未知：当前规则层在同一 tick 允许双方开始动作，动作生效时间和位移结果会自然形成先后优势，而不是简单地把双方攻击合并成“都命中”。

## 3. 对武器设计和展示的收敛

### 3.1 每把武器至少要有“目标结果”和“自身代价”两列

武器卡不能只写：

```text
冲锋盾：命中快、击飞低
```

而应该写成：

```text
冲锋盾：命中快、目标击飞低；自身会向前冲，冲过头会丢失安全位置
```

这与官方资料中“近战武器也可快速投掷、远程武器被近身时要改变处理方式”的学习点一致：玩家需要理解一次动作同时改变双方的空间关系，而不是只看伤害或外观。[官方武器指南](https://bfo.web.sdo.com/web4/guide/wuqi.asp)

### 3.2 空中动作不是额外武器

空中上下文继续作为同一武器的第二种使用方式：

- 收藏仍按一个武器 ID 统计；
- 概览同屏展示地面/空中四项关键差异；
- 生存轮次只调整范围、击退、冷却或稳定性，不增加新按键；
- 详情页解释落点风险和适用地图。

### 3.3 双人同时出招是后续地图验收的最低门槛

竞速地图允许 2–4 人互相攻击，因此地图段落不能只验证单人可达。后续每个窄路、断层和走钢丝段落至少要再做：

1. 两人迎面同时进入；
2. 一人攻击、一人跳跃通过；
3. 一人被击落后 3 秒原处重生；
4. 生存模式中敌人从另一侧进入。

如果只能单人走通，不能写成“竞速/生存共用段落”。

## 4. 当前边界

- 当前实验仍是固定位置和固定输入，不代表真人对战胜率；
- 空中实验没有验证镜头、特效遮挡和移动端触控可读性；
- 双人实验只验证同一规则 tick 的结果存在，不代表多人拥挤下的最终命中顺序；
- 冲锋盾历史 V1 仍保留 `front-guard` 兼容路径，V2 不做格挡的正式权威迁移必须另建 Replay/hash 基线；
- 研究结果只进入文档和开发/测试原型，不把 V2 模式页面直接接入当前生产入口。

本文件关闭的是“攻击者失位、空中动作和同时出招是否能被当前规则/物理观察到”的第一轮问题，不关闭最终武器平衡、真人可读性和发布验收。

# Arena V2 Product 武器概览首屏收敛结果 V1

## 文档状态

- 状态：已接入当前 Product 页面，并通过本地浏览器桌面/窄屏布局检查
- 日期：2026-07-28
- 范围：正式 Product 武器概览的首屏信息顺序、完整数值矩阵折叠、响应式布局
- 证据边界：这是当前源码与本地浏览器 DOM/CSS 的验证，不是实体设备验收、真人可读性结论或发布证据

## 1. 收敛目标

项目的核心长期内容是武器学习。玩家必须能看出武器不是换外观，但第一次进入主页时也不应先面对一张过长的数值表。因此本轮把武器概览分为两层：

```text
首屏：4 个最影响第一次选择的差异
      距离 · 出招 · 击飞 · 收招
      ↓
武器卡：核心动词、命中结果、地图用途、风险、反制、地面/空中语义
      ↓
展开详情：完整 27 行公开数值矩阵
```

首屏四项仍显示精确值、单位、方向语义和箭头，不使用综合评分，也不隐藏武器的真实差异：

| 首屏轴 | 玩家要回答的问题 | 方向语义 |
|---|---|---|
| 有效距离 | 我能从多远开始威胁？ | 越高越有利 |
| 出招速度 | 我需要提前多久出手？ | 越低越有利 |
| 横向击飞 | 命中后能把对手推离多远？ | 越高越有利 |
| 收招安全 | 空挥后多久容易被反击？ | 越低越有利 |

完整矩阵没有删除数据，仍由同一份 Product 武器比较投影生成：9 项主数值、2 项行为数值和 16 项地面/空中场景数值，共 27 个数据行。

## 2. 实现边界

- `ProductUiSceneModel` 仍是比较数据的唯一场景模型来源，UI 没有新增一套平衡字段。
- `#product-weapon-comparison` 只渲染首屏四行；`#product-weapon-comparison-details` 渲染同源的完整矩阵。
- 完整矩阵使用原生 `details/summary` 折叠，不增加新页面、弹窗或复杂交互。
- 武器卡仍承担数值之外的可学习语义：核心战斗语言、命中后果、地图用途、风险、反制以及地面/空中动作解释。
- 窄屏保持一列武器卡；页面本身不得因为完整矩阵产生横向溢出。

## 3. 浏览器验证结果

本地 Product 页面使用当前工作区启动的 Vite 服务验证，浏览器只读检查 DOM/CSS 尺寸，另通过页面真实点击验证详情展开。

### 3.1 桌面视口：1280×720

| 指标 | 收敛前 | 收敛后 |
|---|---:|---:|
| 武器比较首屏数据行 | 27 行 | 4 行 |
| 完整矩阵 | 首屏直接展开 | 27 行数据，默认折叠 |
| Product 武器概览内容高度 | 约 1363px | 约 875px |
| 武器卡 | 3 张 | 3 张 |
| 页面级横向溢出 | 无 | 无 |

收敛后首屏比较区高度约 107px；用户先看到四项真实差异，再决定是否继续展开完整矩阵。

### 3.2 窄屏视口：390×844

| 指标 | 结果 |
|---|---:|
| 首屏快速比较行 | 4 行 |
| 武器卡 | 3 张，单列 |
| 卡片宽度 | 约 332px |
| 完整矩阵 | 27 行数据，默认折叠 |
| 页面级横向溢出 | 无 |
| Product 根节点横向溢出 | 无 |

详情展开后的真实 DOM 检查包含 28 个 `role=row`：1 个表头加 27 个数据行；展开和折叠都没有造成页面横向溢出。

## 4. 结论与未关闭问题

本轮关闭了“武器有数值差异但首屏太密”的信息顺序问题：

1. 新玩家先看到四个最有决策价值的差异；
2. 玩家仍可以在同一页面展开完整数值矩阵；
3. 数值比较与武器语义卡连续出现，能够从“数字差异”继续理解“打法差异”；
4. 3 把正式武器继续来自当前生产 Product 数据，没有把研究候选偷偷注册到生产目录。

本轮在首屏和语义卡之间增加了由同源比较数据派生的差异事实：每张卡最多显示一条优势和一条代价。当前结果为锁链“射程最远 5.00 格 / 击飞最弱 1.19 格”、重锤“击飞最强 2.68 格 / 收招最长 0.40 秒”、冲锋盾“出手最快 0.08 秒 / 射程最近 1.60 格”。这层事实没有综合评分，也不替代完整矩阵；它只把玩家需要自己扫描的极值关系先说清楚。详细规则见[Product 武器数值差异事实原型结果 V1](arena-v2-product-weapon-comparison-facts-v1.md)和[ADR-093](../decisions/093-arena-v2-weapon-comparison-facts.md)。

本轮又把地面/空中比较行中的唯一极值前置到每张卡，最多补充两条场景事实，例如“空中射程最远”或“地面射程最近”。主事实和场景事实都保留原始数值与方向语义；完整矩阵仍负责核对全部场景数据，Canvas 继续使用同源比较表。详细规则见[ADR-095](../decisions/095-arena-v2-weapon-context-comparison-facts.md)。

本轮仍未证明：

- 真人是否能在 10 秒内正确解释四个轴的含义；
- 实体手机/WebView 上的字号、滚动和触控体验；
- 玩家是否会主动展开完整矩阵；
- 数值理解是否会转化为命中归因、地图熟悉和 30/60/120/200 小时留存。

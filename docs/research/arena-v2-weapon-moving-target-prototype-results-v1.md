## 文档状态

- 状态：已完成第一轮“目标侧移 → 武器前摇 → 命中/挥空”验证；多人拥挤、真人可读性和正式 V2 权威迁移仍待验证
- 日期：2026-07-27
- 目的：验证公开的出招速度和地面命中边界，是否真的会影响对手通过基础移动进行反制
- 不代表：最终平衡、最终命中盒、移动目标 AI 或生产模式已经完成

## 1. 实验合同

入口为 `runArenaV2WeaponMovingTargetPrototype()`，位于 `packages/arena-v1-experiment`。实验只在开发/测试工具链运行。

固定条件：

- 使用当前 Arena V1 权威规则层、当前三把武器和轻量物理；
- 攻击者在 tick 0 发起一次攻击，目标初始处于该武器的地面有效距离；
- `stationary` 目标保持不动，作为基线；
- `sidestep` 目标在攻击前摇期间持续向侧方移动，移动方向和速度固定；
- 记录首次命中 tick、命中时目标侧向位移和最终位移；
- 不使用目标的隐藏信息，也不修改规则层命中判定。

## 3. 已经得到的设计证据

### 3.1 前摇不是只用于平衡数字

静止目标三把都能命中；同样的初始距离下，目标侧移会让重锤挥空，而较快的锁链和冲锋盾仍能命中。由此可以把“出招速度”解释为玩家真实可感知的反制窗口，而不是一条孤立的属性条。

### 3.2 武器概览需要同时展示数值和反制语义

如果概览只写“重锤横向击飞高”，玩家仍不知道为什么会挥空。至少要把：

- 出招速度/前摇；
- 命中距离；
- 对手可用的侧移或跳跃反制；
- 挥空后的暴露代价；

放在同一个信息层中。当前网页武器概览已经通过数值比较矩阵显示前摇、距离和风险；研究卡与详情页文案继续负责解释反制方式。

### 3.3 三把原型形成不同的学习问题

| 武器 | 玩家要练的事情 | 对手能学会的反制 |
|---|---|---|
| 重锤 | 提前读落点，换取高击退 | 侧移或跳开慢前摇 |
| 引力锁链 | 保持中距离，抓住移动节奏 | 侧移仍有风险，但可以用障碍和距离规避 |
| 冲锋盾 | 用极短前摇抢直线位置，同时承担自身位移风险 | 让出直线，诱导冲过头 |

## 4. 当前边界

- 目标只做固定侧移，不会观察攻击者，不代表真人反制成功率；
- 只验证一次地面攻击，不覆盖空中动作、连续攻击、同时出招和多人拥挤；
- 侧移发生在宽平台，不代表窄路或边缘上的最终结果；
- 没有把命中率直接当作平衡结论，下一步需要在固定地图路线和对手策略下记录反制成功率、击落率和挥空后的生存率。

本文件关闭的是“公开前摇差异是否会在移动目标面前转化为命中/挥空差异”的第一轮问题，不关闭最终平衡。

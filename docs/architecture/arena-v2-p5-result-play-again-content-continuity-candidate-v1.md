# Arena V2 P5 结算再来一局内容连续性 Candidate V1

状态：`code-written-not-run`。本批按开发优先执行，未运行测试、类型检查、构建、压测或设备验证。

## 目标

玩家在结算页选择“再来一局”时，继续使用上一局的模式、武器和地图，保持正在形成的武器手感与地图记忆，不被导航或 Registry 变化静默切换内容。

## 实现

- 只在 `result-reward → play-again` 同步建立临时内容锁；下一目标与普通模式选择不受影响。
- 建锁前要求请求模式等于上一局模式；想换模式必须走下一目标或模式选择。
- 开局内容 Provider 优先读取锁定武器和地图。
- 若 active Registry 已撤下上一局武器，直接拒绝再来一局，不自动换成目录第一把。
- 内层返回 Match Start 后再次核对模式、武器、地图；漂移按开局结果不确定失败关闭。
- 无 Profile 字段、无持久状态、无新选择、无异步、无资源；同步开局调用结束即释放临时锁。

## 顺延验证

- 纯连续性合同单测；
- 结算再来一局三模式集成用例；
- Registry 撤下原武器、重入修改选择、开局失败与清理用例；
- 完整测试、类型、构建、压力、浏览器和设备证据。

以上统一顺延到下一验证阶段，不阻塞后续开发。

# Arena V2 武器设计与研究框架

## 文档状态

- 状态：初稿，已完成第一轮热血英豪研究、公开数值原型和无渲染上下文验证
- 日期：2026-07-27
- 研究重点：热血英豪的武器对战逻辑

## 学习目标

我们学习热血英豪，不是为了复制武器清单，而是为了理解：

- 为什么一把武器能形成独立的战斗方式；
- 武器如何把命中转化为位置变化；
- 为什么武器需要前摇、收招、距离和风险；
- 武器如何与地形产生不同价值；
- 对手如何识别、躲避和反制；
- 复杂武器如何还原成一个最基础的功能版本。

官方资料和公开介绍显示，热血英豪的核心体验与时机、地形、武器/道具使用和对手心理密切相关，而不是单纯依赖复杂输入。[热血英豪介绍](https://zh.wikipedia.org/wiki/热血英豪)、[官方武器指南](https://bfo.web.sdo.com/web4/guide/wuqi.asp)

## 武器基础公式

```text
核心动作
  + 命中结果
  + 使用风险
  + 地图用途
  + 对手反制
  = 一把可理解的武器
```

每把武器第一版只保留：

- 一个核心动词；
- 一个地面或空中变化；
- 一个主要地图用途；
- 一个明显失败风险；
- 一个玩家可理解的反制方式。

从第二轮研究开始，每把武器还必须至少有两个动作上下文：地面和空中。上下文不等于增加两个新按键，而是同一个攻击输入在不同移动状态下产生不同的距离、前摇、命中结果或风险。武器概览必须能并排展示这两个上下文的核心差异。

```text
公开武器卡
  ├─ 核心动词
  ├─ 主动作 8 项数值
  ├─ 地面上下文：距离 / 前摇 / 横向作用 / 垂直作用
  ├─ 空中上下文：距离 / 前摇 / 横向作用 / 垂直作用
  ├─ 代价：挥空、冷却、自身位移或路线暴露
  └─ 反制：方向 + 跳跃即可理解
```

## 基础功能族候选

| 功能族 | 核心动词 | 主要空间关系 |
|---|---|---|
| 重击退 | 推 | 把目标推向边缘或危险区 |
| 拉扯 | 拉 | 把目标拉离安全位或拉入攻击距离 |
| 冲锋 | 冲 | 自己位移并改变双方站位 |
| 直线压制 | 刺 / 射 | 用距离争夺安全路线 |
| 投掷打断 | 投 | 远程打断并迫使对手移动 |
| 垂直控制 | 击飞 / 下砸 | 改变上下高度和落点 |
| 区域控制 | 控 | 限制一段路线或一个平台 |

第一轮不要求所有功能族都进入生产，只用于建立设计语言。

## 当前三把武器的基础版本

### 锤子：重击退

- 核心动作：近距离重击并产生高击退。
- 地图用途：边缘、窄桥、断层和平台入口。
- 主要风险：前摇明显，挥空后收招时间长。
- 反制方式：提前离开攻击线、诱导挥空、从侧面接近。

### 链条：拉扯

- 核心动作：中距离命中后改变目标位置。
- 地图用途：把目标拉离安全平台，或把目标拉入自己的攻击距离。
- 主要风险：需要准确瞄准，空挥后容易失去主动权。
- 反制方式：横向移动、跳跃、利用障碍物和距离。

### 冲锋盾：冲撞

- 核心动作：向面对方向快速位移并产生撞击。
- 明确边界：不提供格挡，不提供正面减伤或无敌。
- 地图用途：窄路、直线平台和边缘抢位。
- 主要风险：冲过头、自身掉落、被诱导改变位置。
- 反制方式：横向闪避、让出路线、利用高低差。

## 武器研究卡模板

后续每研究一件参考武器，必须填一张卡：

| 字段 | 要回答的问题 |
|---|---|
| 武器身份 | 玩家一眼知道它想做什么吗？ |
| 核心动词 | 推、拉、冲、刺、投还是控区？ |
| 命中条件 | 距离、方向、地面/空中和时机是什么？ |
| 命中结果 | 击退、拉近、击飞、打断还是限制路线？ |
| 地图价值 | 哪类地形让它变强？ |
| 失败风险 | 挥空、误判或使用后会损失什么？ |
| 反制方式 | 对手能否用简单操作理解并躲开？ |
| 最小版本 | 去掉复杂效果后，最基础的 Arena 版本是什么？ |
| 生存成长 | 只提高哪些临时属性，不增加什么新按钮？ |
| 反馈要求 | 玩家必须看到、听到和感受到什么？ |
| 上下文差异 | 地面和空中动作各自改变了哪个数值和空间问题？ |

## 武器平衡维度

后续平衡不能只看胜率，还要看：

- 使用率和拾取率；
- 命中率与有效命中率；
- 造成击飞和造成淘汰的比例；
- 地图依赖程度；
- 挥空后的风险；
- 地面/空中上下文是否真的产生可读差异；
- 对手是否知道如何反制；
- 新玩家是否能理解，高水平玩家是否能进一步研究。

## 生存模式中的武器等级

- 武器基础动作和命中语义保持不变。
- 生存中的等级是本局临时状态，结束后重置。
- 等级优先改变范围、击退、冷却或稳定性等可测参数。
- 不因为轮次提高而突然增加新的操作按键。
- 同一把武器在第一轮和第十轮可以不同，但玩家必须能看懂差异。

研究端已经用等级 1/5/10 的实际战斗原型验证了“属性不同但操作语法不变”是可行的：重锤、锁链、冲锋盾的目标横向控制力会实际改变目标位移。当前原型已经从冲量端口收敛为等级专属 Action/Equipment Definition，地面和空中数值分别公开，冲锋盾的自身位移风险保持基础值不随目标控制成长。统一百分比仍不是最终方案：重锤在等级 5 到 10 受到物理速度上限后位移不再增加，所以正式成长必须按武器核心问题选择字段，并在概览中同时展示基础值、本局临时等级值、地面/空中差异和风险变化；证据见[生存临时武器等级原型](../research/arena-v2-survival-loop-prototype-results-v1.md#7-生存临时武器等级实际战斗原型)与[ADR-051](../decisions/051-arena-v2-survival-tier-formal-definition.md)。

## 研究顺序

第一轮研究 12 件代表性参考武器，按功能族分类；不立即制作全部武器。先提炼 6 个基础原型，再进行无渲染模拟、占位表现和 1v1/生存实测。

当前三把基础原型已经通过同一权威规则层完成地面/空中、命中/挥空和击飞差异验证；结果见[武器上下文无渲染原型结果](../research/arena-v2-weapon-prototype-results-v1.md)。这只关闭“差异能否形成”，不关闭“地图实战是否公平”和“真人是否能快速理解”。

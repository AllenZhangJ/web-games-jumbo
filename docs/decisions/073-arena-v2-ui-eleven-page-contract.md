# ADR-073：Arena V2 以 11 个信息入口和一个共享竞技准备模板收敛界面

## 状态

已接受，适用于 V2 开发/测试工具链和后续 Product 导航设计；真实页面布局、触控和真人阅读率仍待验证。

## 日期

2026-07-28

## 背景

现有文档把“加载页”列入 11 个页面，但无渲染原型把“竞速准备”单独列出，导致页面数量和导航结构不一致。项目目标又要求页面简单入手、武器与地图承担主要深度，因此必须先固定信息入口与模板复用边界。

## 决策

1. 11 个信息入口固定为：加载、首页、模式选择、角色选择、竞技准备、生存准备、武器收藏、武器详情、地图收藏、地图详情、结算/奖励。
2. 1v1 与竞速共用 `match-prep` 页面模板，通过模式目标、参与人数、终点/重生规则等字段变化表达差异，不新增 `race-prep` 页面。
3. 生存使用独立 `survival-prep`，因为它有无武器开局、20 秒供给、一次复活和第二次终局等不同决策节奏。
4. 首页、模式、准备和结算页面的首屏最多展示 3 个信息块；武器和地图详情可以延后展示反制、个人记录和完整路线信息，但不能增加必经点击。
5. 参考弹壳特攻队的内容只转译为“快速进入、行为化武器说明、场景化选择和结算后的下一目标”，不迁移宠物、科技、部件、活动、商城、多货币或 Roguelike 技能组合。

## 不采用

- 把 1v1、竞速和生存各自扩展成一套独立局外系统；
- 为了凑页面数量新增训练场、商城、活动或复杂养成入口；
- 用单一战力分数取代武器的真实动作数值、地图空间和反制说明。

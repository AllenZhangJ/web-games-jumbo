## 2. 与 V2 目标的差距

当前链路验证了“快速开始”和“武器被看懂”，但还没有把 V2 的三个模式和地图长期目标接入页面。以下内容明确标记为缺口，不把 V1 页面误写成 V2 完成：

| V2 信息问题 | 当前状态 | 下一步原型 |
|---|---|---|
| 我现在要玩 1v1、竞速还是生存？ | 缺少模式选择页 | 三个模式卡，展示目标和推荐时长 |
| 这张地图要熟悉什么？ | 缺少地图选择/详情 | 六段路线缩略图、难度六维、最佳记录 |
| 生存模式为什么值得重开？ | 缺少生存准备与结算 | 坚持时间、击落次数、武器轮次、下一目标 |
| 这把武器地面和空中怎么用？ | 概览已显示基础差异、命中结果和地图用途 | 详情页补动作时序、适用地形和反制演示 |
| 200 小时还差什么？ | 没有武器收集进度总览 | 武器索引进度、地图熟练记录和模式记录 |

## 3. 界面收敛结论

V2 首批仍不新增商城、皮肤、头像框、展示台、训练场或复杂养成页面。优先把信息压缩到以下最小页面链路：

```text
主页
 → 模式选择
 → 角色/武器/地图准备
 → 对局
 → 结算与奖励
 → 立即重开或查看收集进度
```

武器详情是学习页，不是新的成长系统；地图详情是路线学习页，不是编辑器；生存结算是重开理由，不增加新的货币或复杂任务树。

## 4. 下一轮验收标准

- 新玩家无需看教程，能在 10 秒内选模式并进入准备页；
- 准备页能在一屏内比较角色、武器和地图的核心差异；
- 结算页能在 2 次点击内重开或切换模式；
- 武器索引能显示已收集/未收集和下一件目标，但不引入战斗外数值加成；
- 地图页能同时说明竞速目标和生存复用方式。

# ADR-056：武器先按可学习的战斗语言扩展

- 状态：已接受，适用于 V2 武器研究与新增武器评审
- 日期：2026-07-27
- 范围：`packages/arena-v1-experiment` 的参考武器研究卡与开发/测试工具链

## 背景

热血英豪的武器数量很多，但可迁移的价值不在于复制每件武器的名称或招式数量，而在于玩家反复学习的战斗问题：如何冲入、如何封路、如何改变双方距离、如何读招反制、如何控制直线、如何绕后以及如何预判延迟重击。

如果每个新武器都直接以独立名称和美术开始制作，团队会很快得到许多外观不同、数值却无法解释的武器。另一方面，只按“近战/远程”分类又无法说明地图、反制和生存模式中的实际差异。

## 决策

将 12 件参考武器的原始功能族归并为 7 种 Arena 战斗语言：

- 冲入；
- 封路；
- 换位；
- 读招反制；
- 直线压制；
- 绕后；
- 延迟重击。

每种战斗语言必须声明：

1. 为什么有效；
2. 至少四个必须公开或调优的数值轴；
3. 对手用移动、跳跃或路线选择如何反制；
4. 哪些地图空间能放大其价值；
5. 适合 1v1、竞速、生存中的哪些模式；
6. 不增加复杂按键的最小 Arena 版本。

研究卡到战斗语言的映射只存在于开发/测试工具链，不能成为生产规则、存档或玩家收藏 ID。正式武器仍需通过 Definition、Registry、Rule/Core 原型和地图结果验证后才能进入产品。

## 被考虑的替代方案

### 每件参考武器都做成一个独立功能族

- 优点：看起来内容数量增长快；
- 放弃原因：会复制参考游戏的复杂度，无法判断新增武器到底带来了新的学习问题还是只换了外观。

### 只按近战、远程、投掷分类

- 优点：分类简单；
- 放弃原因：没有表达命中后的距离变化、延迟预判、地图边缘后果和反制窗口。

### 只用一个总评分决定武器定位

- 优点：展示成本低；
- 放弃原因：总评分掩盖收益与风险的方向，无法解释为什么同一件武器在宽平台和窄路上价值不同。

## 后果

正面影响：

- 新武器评审先回答“增加了什么学习问题”，再决定名称、动作和美术；
- 研究卡、公开数值、地图原型和模式适配拥有共同索引；
- 7 种语言足以覆盖当前 12 件参考案例，同时保留后续发现新语言的空间；
- 竞速和生存可以复用同一语言，但根据地图和压力调整数值，不需要新增按键。

限制：

- 功能语言是研究抽象，不代表最终正式武器必须严格一一对应；
- “适合模式”是候选判断，必须通过真实对局和真人理解数据复核；
- 当前五种扩展语言（直线压制、封路、延迟重击、读招反制、绕后）已经有统一 Rule/Effect/Targeting 原型；冲入、换位仍以正式武器与生存 Definition 为主要证据，其余语言仍不是生产武器。

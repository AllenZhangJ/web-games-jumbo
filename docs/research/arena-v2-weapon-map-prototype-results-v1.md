# Arena V2 武器地图边缘原型结果 V1

## 文档状态

- 状态：已完成第一轮“规则命中 → 轻量物理 → 地图后果”验证；移动目标、多人拥挤、真人可读性和正式 V2 权威迁移仍待验证
- 日期：2026-07-27
- 目的：验证武器的横向命中结果是否会在不同地图空间中形成可观察的路线后果
- 不代表：最终平衡、正式地图资产、最终武器数量或生产模式已经完成

## 1. 实验合同

入口为 `runArenaV2WeaponMapPrototype()`，位于 `packages/arena-v1-experiment`。实验只在开发/测试工具链运行，不进入生产入口。

每个场景固定以下条件：

- 规则层使用当前 `createArenaV1RuleEngine()` 和 Stage4 武器动作定义；
- 规则层产生的 `APPLY_IMPULSE` 通过 mutation port 直接送入当前轻量物理世界；
- 角色使用正式角色碰撞体和固定 tick；
- 攻击者与目标均从明确位置开始，目标不移动，攻击在 tick 0 发起；
- 每把武器分别测试宽平台、当前 KZ 灰盒窄路和边缘平台；
- 记录首次命中、规则横向冲量、目标水平位移、目标是否跌破 `killY` 以及最终地图后果。

这不是最终对战模拟，而是一个可重复的因果探针：如果同一命中结果在不同空间上没有任何可观察差异，就不能把“适合边缘/窄路”写成设计结论。

## 3. 已经得到的设计证据

### 3.1 命中结果和地图空间确实形成组合差异

- 宽平台上三把武器都命中但不直接造成掉落，玩家仍有时间继续移动和反制；
- 窄路上重锤和锁链的横向作用会把目标送出路线，冲锋盾则保留目标并换取自身位置；
- 边缘平台上重锤和冲锋盾形成击落，锁链更像是改变站位而不是直接结束位置交换。

因此武器概览中的“地图用途”不是装饰文案，至少在当前灰盒尺度下可以对应可复现的空间结果。

### 3.2 当前三把武器形成不同的学习问题

| 武器 | 玩家要学的地图问题 | 当前证据 |
|---|---|---|
| 重锤 | 什么时候值得等待慢前摇来换取强击落 | 宽平台安全、窄路和边缘出界 |
| 引力锁链 | 什么时候拉位足够，什么时候还需要追击 | 宽平台与边缘不直接出界，窄路可以出界 |
| 冲锋盾 | 是否用自身位移换立即命中和抢位 | 首次命中最快；边缘可击落，但目标击飞弱 |

### 3.3 这轮实验暴露了一个重要的数值展示要求

单独展示“横向击退”仍然不够。玩家还需要知道：

- 该击退在宽平台上通常只是换位置；
- 在窄路或边缘上可能直接变成击落；
- 目标初始离边缘多远，会改变同一把武器的结果。

因此后续武器详情页应把“命中结果”显示为语义，而把“地图用途”显示为条件，不把一次实验的出界概率伪装成固定属性。

## 4. 当前边界

- 目标本轮不移动，不能替代真实对手的走位和反制；
- 只验证地面动作，空中动作还需要分别验证落点与垂直控制；
- 窄路使用当前自有 KZ 灰盒 surface，不代表任何 CS1.6 原地图资产；
- 未验证 2–4 人拥挤、同时攻击、复活点和生存敌人压力；
- 未验证真人是否能把“命中—击退—掉落”正确归因到武器或地图。

本文件关闭的是“横向命中结果是否会被地图空间放大”的第一轮问题，不关闭最终平衡和发布验收。

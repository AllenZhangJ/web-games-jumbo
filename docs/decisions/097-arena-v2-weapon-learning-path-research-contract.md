# ADR-097：逐件武器研究先按三步学习路径收敛

- 状态：已接受，已接入研究工具链
- 日期：2026-07-28
- 范围：六件逐件研究武器的概览适配层和独立可读性研究页；不进入生产成长、奖励、存档或 MatchCore

## 背景

热血英豪式武器的学习对象不是一组静态数值，而是“输入上下文 → 可观察结果 → 地图关系 → 失败代价”的动作链。当前六件武器已经有逐动作研究卡、地面/空中数值和 Replay，但这些内容如果同时铺开，玩家会看到很多信息，却不一定知道先学什么、下一步比较什么。

## 决策

每件逐件研究武器从已经声明的动作顺序派生三步研究路径：

1. `core`：取第一件基础动作，先学核心动词和最小可重复结果；
2. `context`：取第一个与基础动作上下文不同的动作，学习地面/跑动/空中/蓄力/延迟等状态变化；
3. `map`：取动作链最后一个动作，学习地图关系、失败代价和反制。

每一步保留来源动作 ID、输入、上下文、玩家决策、观察重点、失败代价和对应数值轴；数值轴继续沿用动作研究卡的 `must-measure` / `research-only` 状态。页面使用折叠学习路径，避免把三步内容与数值矩阵同时展开。

## 被考虑的替代方案

### 只显示核心动词和完整数值矩阵

- 放弃原因：能看见差异，但没有学习顺序，无法验证玩家是否先掌握基础动作再迁移到地图。

### 为每件武器手工写一套教学流程

- 放弃原因：动作研究卡调整后容易漂移；从来源动作顺序派生，才能保持研究页与逐动作证据同源。

### 把三步路径做成正式任务、奖励或解锁

- 放弃原因：当前没有真人完成率和 200 小时数据，不能把研究假设提前固化为生产成长系统；先验证理解顺序，再决定是否进入产品成长。

## 后果

- 六件武器都有可比较的“先学、再换上下文、最后放进地图”结构，且每一步能追溯到具体动作和数值轴。
- 研究页不再只展示武器有什么，也展示玩家应观察什么以及失败要付出什么代价。
- 当前路径是研究提示，不代表三分钟内一定学会，也不代表 200 小时收藏进度已经成立；仍需真人首见时间、复述和地图归因数据。

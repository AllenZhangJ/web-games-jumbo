# Arena V2 P5 模式选择规则摘要合同 Candidate V1

状态：`code-written-not-run`。本批按“开发优先”推进，未运行测试、构建、类型检查、压测或设备验证。

## 目标

模式选择页必须在进入准备页之前，用三张卡说明真正影响选择的差异：

- 常规 1v1：击落唯一对手，练习武器进攻与反制。
- 竞速：2–4 人、地图板块不掉落、允许攻击干扰、掉落 3 秒后不限次数复位、先到终点获胜。
- 生存：默认空手、靠近拾取会替换当前武器、每 20 秒刷新 3 把、10 秒未拾取消失、存活越久压力和武器越强、第一次掉落复活且第二次结束。

## 实现边界

`arena-v2-mode-selection-copy-candidate-v1.ts` 只把现有权威 tick、刷新数量和复活上限投影为玩家可读摘要，不拥有模式规则、选择状态或游戏行为。竞速“2–4 人”直接读取两张共享 KZ Route Definition，并要求两条路线的人数边界完全一致；“地图板块不掉落”直接绑定对应 Map Definition，并要求它们均不存在 `collapse-surfaces` 事件。生存“武器越强”直接绑定连续 1–10 级、每轮前进一级且射程、冲量、硬直不回退、冷却不变差的武器等级目录。竞速与生存的时间数值如果不能整秒表达，会在组合加载时失败关闭，避免显示旧文案。

Arena 三模式本地可玩宿主不再维护一份手写模式说明，而是直接消费该只读三项列表。更完整的武器、地图和压力说明仍保留在模式准备页，选择页只承担快速判断。

390px 窄屏的模式卡单独使用 112px 高度和最多三行说明，保证生存的刷新、消失、强化与两次掉落规则不会沿用通用 82px 两行卡片而被提前截断；角色、武器和地图卡尺寸不变。宽屏三列模式卡保持两行摘要。

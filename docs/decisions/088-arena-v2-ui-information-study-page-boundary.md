# ADR-088：11 个局外页面先用独立研究页验证信息合同

- 状态：accepted
- 日期：2026-07-28
- 范围：Arena V2 11 个局外信息入口、页面首屏合同、关键流程和研究/生产边界

## 背景

Arena V2 已经收敛为 11 个局外信息入口，但页面合同此前主要存在于无渲染原型，研究员无法直接观察页面职责、首屏密度和流程顺序。若直接改生产导航，又会把尚未通过真机和真人验证的假设写入正式入口。

## 决策

1. 新增独立 `ui-information.html` 研究页，直接消费 `runArenaV2UiInformationPrototype()` 的 11 页合同和四条流程，不复制第二份页面定义。
2. 研究页必须展示页面问题、首屏信息、延后信息、主/次动作、点击预算和支持模式；流程页必须展示页面顺序和主要操作数。
3. 研究页使用 `noindex,nofollow`，不进入 `scripts/build.ts` 的生产入口，不依赖 MatchCore、存档、真实 Product 状态或局外持久化。
4. CSS 只提供研究验证所需的窄屏布局和基本触控尺寸，不把静态 CSS 断点测试表述为真机通过。
5. 真机触控、字号可读性、真人阅读率和结算后再次开始率仍需单独验收；研究页通过不能触发生产导航迁移。

## 被拒绝的替代方案

### 直接把 11 页合同写入当前生产 V1 导航

拒绝原因：当前生产 V1 状态机和 V2 页面合同不是同一套状态，直接接入会把研究假设伪装成已实现功能。

### 为研究页再维护一份页面数组

拒绝原因：页面列表、首屏规则和点击预算会发生漂移，研究结果无法追溯到唯一合同。

### 只用 CSS/DOM 快照宣称手机和真人验证通过

拒绝原因：静态 DOM 只能证明工程结构，不能证明触控命中、真实字号、理解率或再次开始行为。

## 后果

- 研究员可以直接浏览 11 个页面合同和四条关键流程，继续收敛信息架构而不污染生产入口。
- 武器数值概览、地图路线和生存重开都可以在局外页面合同中继续被检查，但仍保持研究/生产分层。
- 真机和真人测试有了稳定的研究入口，后续记录可以绑定页面合同版本，而不是依赖截图猜测。

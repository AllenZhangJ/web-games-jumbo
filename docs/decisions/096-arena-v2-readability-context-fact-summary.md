# ADR-096：可读性研究页增加场景差异速览

- 状态：已接受，已接入研究工具链
- 日期：2026-07-28
- 范围：六件逐件研究武器的独立可读性页面；不进入默认生产 UI、MatchCore、Replay 或存档

## 背景

研究页已经展示六件武器的四项首屏快速数值和地面/空中完整矩阵，也已有一道地面/空中差异任务。但玩家要先扫描矩阵，才能发现“哪把武器在哪个场景最突出、代价是什么”。这会把数值理解验证变成表格寻找任务，无法单独观察首见信息是否清晰。

## 决策

1. 从同一份六件研究武器矩阵派生“场景差异速览”，不另建 UI 数值来源。
2. 只收录唯一最大/最小值；并列值不生成事实，避免把并列误写成赢家。
3. 数值方向决定“优势/代价”的语义：前摇、收招等越低越有利；自身位移风险越低越有利；其他公开轴按数值越高越有利解释。
4. 每件武器最多显示一条优势和一条代价，优先空中上下文，再按距离、覆盖、前摇、恢复、横向作用、垂直作用和高度差的顺序扫描。
5. 每条事实必须保留武器名、场景、数值轴、原始值、单位和方向；速览不是综合评分，也不替代完整矩阵。
6. 速览只服务研究员和参与者页面，用于观察首见可读性；生产武器卡继续使用 Product 自己的同源场景事实合同。

## 被考虑的替代方案

### 继续只展示完整矩阵

- 放弃原因：玩家需要先横向扫描多行，才能形成场景差异印象；这与“3 分钟掌握基础操作、快速理解武器位置”目标冲突。

### 为六件武器手工填写固定标签

- 放弃原因：矩阵或 Definition 调整后容易漂移，无法证明页面结论仍来自当前数值。

### 计算综合战斗力或场景评分

- 放弃原因：会把地面与空中、优势与代价错误相加，掩盖热血英豪式的空间取舍，也不利于后续平衡解释。

## 后果

- 研究页现在既有快速结论，也保留完整数值核对面；研究参与者可以直接看到场景、差异和原始单位。
- 并列值和不可比较字段会被跳过，不能用文案伪造差异。
- 当前自动化矩阵生成 10 条速览事实；这不是真人理解率，也不是生产平衡结论。
- 未来若调整矩阵来源，速览会随矩阵重新生成；仍需重新执行真人可读性和设备验证。

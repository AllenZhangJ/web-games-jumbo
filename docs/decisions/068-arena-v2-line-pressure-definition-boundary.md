# ADR-068：直线压制先以单一攻击线 Definition 验证

- 状态：accepted
- 日期：2026-07-28
- 范围：Arena V2 直线压制研究候选

## 背景

首发六种战斗语言中，直线压制是第一个需要从研究卡迁移到 Definition 的候选。已有语言原型证明它可以通过 Rule/Targeting/Effect 产生“等待命中、提前离开未命中”的结果，但还没有把地面/空中动作和公开数值绑定成一份可审计快照。

如果直接加入生产目录，容易把“远距离攻击”误做成自动追踪或复杂射击系统，也会让玩家无法理解它和重锤、锁链的差异。

## 决策

直线压制的最小 Definition 只保留：

- 地面与空中两个动作身份；
- 一条可见、可回应的正面攻击线；
- 固定重复间隔；
- 低至中等击退和明确收招；
- 由权威动作字段投影出的 11 个公开数值轴。

原型状态固定为 `research-only`。它可以进入无渲染 Rule/Core 验证，但不能进入生产 EquipmentRegistry、玩家存档或正式武器页面。

公开数值投影统一使用 `arena-definitions` 的 `projectArenaWeaponPublicNumbers`；生产表现层和研究原型不得分别实现覆盖宽度、方向容错或击退距离公式。

## 被拒绝的替代方案

### 自动跟踪投射物

拒绝原因：会抹掉攻击线和路线判断，无法验证直线压制的核心反制。

### 多套瞄准与弹药系统

拒绝原因：与“3 分钟掌握基础操作”冲突，也会把武器深度转成操作复杂度。

### 只添加概览文字，不创建 Definition

拒绝原因：文字无法证明命中、空放、地图后果和数值之间真实一致。

## 后果

- 研究候选现在有地面/空中数值、命中 tick 和反制证据，后续真人测试有明确对象；
- 生产武器仍保持三把，避免研究内容污染正式目录；
- 共享投影公式成为生产 UI、研究审计和后续候选的共同边界；
- 直线压制进入生产前仍需 KZ 地图、反馈和真人可读性证据。

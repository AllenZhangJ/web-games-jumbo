# ADR-107：研究武器必须通过六项价值链结构审计

## Status

Accepted（Arena V2 研究工具链）

## Date

2026-07-28

## Context

ADR-106 已定义武器独立性的六项价值链，但如果它只存在于文字文档，后续新增案例仍可能漏掉失败成本、地图后果或玩家反制。六件热血英豪深研案例已经拥有动作、数值复核和研究边界，需要把这套判断变成可执行的结构审计。

## Decision

在研究工具链中固定 `auditArenaV2WeaponValueChain()` 和六件案例的汇总报告。每个研究案例必须提供：

1. 动作身份；
2. 承诺时间；
3. 空间条件；
4. 命中后果；
5. 失败成本；
6. 反制与反馈。

审计输出 `passed/blocked` 及缺失项。它只检查研究合同是否完整，不写入生产 Registry，不替代数值平衡、Replay、设备和真人验收。

## Alternatives Considered

### 继续只靠文档评审

拒绝：无法防止新增案例遗漏字段，也无法提供稳定的负向验证。

### 用单一综合分替代六项门槛

拒绝：综合分会隐藏“高覆盖但高收招”或“高击飞但低可读性”的取舍，和武器概览的逐轴展示目标冲突。

### 直接把审计通过视为生产就绪

拒绝：研究合同完整不代表权威动作、反馈资产、设备表现和真人理解已经完成。

## Consequences

- 六件现有案例已被自动证明具备完整研究结构；
- 新增研究武器时，缺少动作链任何一环都会得到明确阻断原因；
- 研究、数值展示和生产迁移仍保持分层，不会因为审计通过而扩大生产范围；
- 未来可在不改审计语义的情况下，为 Definition、Replay 和真人测试增加更强的独立门禁。

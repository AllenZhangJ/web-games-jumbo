# Arena V2：KZ 分叉路线镜头观察结果 V1

## 状态

- 状态：研究用正交镜头观察合同已通过，移动端纵向与横向首屏均能同时包含两条分叉的前两个路线点
- 日期：2026-07-28
- 范围：迷宫/走钢丝的选择与复活重入观察，不包含实际 Renderer、最终美术、攻击特效和真人理解
- 生产影响：只存在于 `arena-v1-experiment` 研究工具链，不改变生产镜头配置

## 1. 观察合同

镜头只验证一个必要条件：玩家在选择 tick 120 和复活重入后的观察窗口中，能在同一个正交视野里看到两条路线的前两个研究路线点。它不把“几何在视锥内”写成“真人已经看懂”。

本轮固定两个设备比例：

| 视口 | 像素 | 研究世界高度 | 研究世界宽度 |
| --- | --- | ---: | ---: |
| mobile-portrait | 390 × 844 | 8.4 | 3.882 |
| mobile-landscape | 844 × 390 | 5.2 | 11.253 |

纵向视口的世界高度从 8.0 调整到 8.4，是因为走钢丝两条前段路线的横向余量最小；调整后仍然保持独立分叉可见，而不是通过隐藏路线或裁掉分叉解决问题。

## 2. 结果

| 段落 | 阶段 | 视口 | 最小横向余量 | 最小纵向余量 | 两条路线可见 |
| --- | --- | --- | ---: | ---: | --- |
| 迷宫 | 选择 | 纵向 | 0.441 | 2.000 | 是 |
| 迷宫 | 重入 | 纵向 | 0.441 | 2.000 | 是 |
| 迷宫 | 选择 | 横向 | 4.127 | 0.400 | 是 |
| 迷宫 | 重入 | 横向 | 4.127 | 0.400 | 是 |
| 走钢丝 | 选择 | 纵向 | 0.066 | 3.100 | 是 |
| 走钢丝 | 重入 | 纵向 | 0.066 | 3.100 | 是 |
| 走钢丝 | 选择 | 横向 | 3.752 | 1.500 | 是 |
| 走钢丝 | 重入 | 横向 | 3.752 | 1.500 | 是 |

走钢丝纵向的 `0.066` 余量是当前最危险的镜头边界：合同通过，但已经接近裁切阈值，不能直接视为舒适可读。后续镜头需要在真实画布上验证角色、武器、命中提示和路线标识叠加后是否仍然看得清。

## 3. 边界与下一步

- 当前只使用路线点和正交视锥数学，没有启动 Renderer，也没有截屏证据。
- 没有验证玩家是否能在 5 秒内说出哪条更快、哪条更容易被攻击打断。
- 没有验证多人角色、武器特效、复活提示和 HUD 是否遮挡分叉。
- 下一步应把四条分叉接入实际灰盒画布，在 390 × 844 和 844 × 390 两种视口下生成截图，再做真人路线选择任务。

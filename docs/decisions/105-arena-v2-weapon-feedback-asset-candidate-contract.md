# ADR-105：命中反馈先固定候选资产合同，再绑定最终资产

## Status

Accepted（研究工具链）

## Date

2026-07-28

## Context

Arena 已经把命中确认、支撑面转移、击落、攻击被避开和路线失误固定为五种权威反馈语义，并投影为 `WeaponFeedbackPresented`。但“有视觉 Cue/音频 Cue”不等于最终声音和特效已经交付：当前灰盒仍使用占位表现，尚无目标设备、低动效和真人反馈证据。

如果现在直接把候选武器标记为完成，后续容易出现所有结果共用一个音效、低动效没有替代、设备上看不出目标身份，以及研究占位资产被误放进正式资源包的问题。

## Decision

在研究工具链增加五类候选资产合同。每类反馈固定：

- 一个候选视觉资产 ID；
- 一个候选音频资产 ID；
- 一个低动效视觉资产 ID；
- 一个语义职责；
- `candidate` 状态和三个未完成验收标志。

资产合同只按权威反馈语义索引，不根据位置或渲染结果重新判断命中原因。审计固定要求最终视觉、最终音频、设备可读性和真人因果理解全部完成后，才允许从候选资产阶段进入生产迁移评审。

## Consequences

- 反馈资产交付可以逐类追踪，不会用一个通用“命中反馈”掩盖五类结果差异；
- 低动效成为合同字段，不再在最终验收时临时补降级方案；
- 当前审计仍为 `blocked`，不会改变生产 Registry、存档、收藏 ID 或 MatchCore 规则；
- 资产 ID 不是文件存在证明，必须另外提交正式资产、许可、设备和真人证据。

# ADR-079：局外界面研究必须区分官方承诺、信息模式与 Arena 翻译

- 状态：accepted
- 日期：2026-07-28
- 范围：Arena V2 弹壳特攻队界面研究目录、局外页面合同和后续界面原型

## 背景

弹壳特攻队的官方商店页、官方生存指南和版本记录同时包含核心卖点、武器行为说明和长期内容扩展。如果把这些内容直接写成 Arena 的功能清单，容易把“参考对象如何表达体验”误读成“本项目必须复制的系统”，并且会让 11 个信息入口膨胀为 11 套复杂管理系统。

## 决策

1. 研究目录使用四类字段区分 `sourceClaims`、`informationSignals`、`arenaTranslation` 和 `notToCopy`；来源事实不能与 Arena 设计推导混写。
2. 官方商店页只能支持核心定位和承诺的观察；官方指南可以支持武器行为与场景化信息的观察；版本记录只用于识别复杂度边界，不用于生成 Arena 系统。
3. 所有外部界面证据固定为 `research-only`，不进入生产导航、生产 Definition、货币、活动或收藏系统。
4. Arena 继续以 11 个信息入口和一个共享竞技准备模板为页面合同；新增页面必须先证明它解决了独立玩家问题，并通过无渲染原型和真人可读性测试。
5. 参考对象的自动锁定、Roguelike 技能池、宠物、科技、部件、活动、多货币和社交系统不进入当前版本范围。

## 被拒绝的替代方案

### 按参考对象的版本记录逐项复刻页面

拒绝原因：会把局外复杂度从武器/地图学习转移到系统管理，偏离 3 分钟上手和 200 小时收集目标。

### 只保存官方链接，不保存结构化事实

拒绝原因：无法复核某条设计建议到底来自官方资料、研究推导还是团队偏好，后续也无法做来源边界检查。

### 把 Arena 的信息推导写入官方事实字段

拒绝原因：会让研究卡看起来像外部资料直接证明了 Arena 的页面结构，掩盖仍需真人测试的假设。

## 后果

- 界面研究能明确回答“官方资料说了什么”和“我们只借鉴了什么”；
- 研究目录增加字段维护成本，但后续检索和评审更稳定；
- 11 个页面合同不扩张，真正的长期内容继续由武器、地图段落和模式记录提供；
- 真人字号、阅读率、数值解释率、结算后再次开始率仍是未完成的独立验证，不会被官方资料目录替代。

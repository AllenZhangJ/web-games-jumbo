# Arena V2 首发武器生产迁移门禁结果 V1

- 状态：门禁已建立，六个候选均未晋级生产

- 适用范围：Arena V2 开发/测试工具链

- 关联决策：[ADR-074：首发武器必须通过五项生产迁移门禁](../decisions/074-arena-v2-weapon-production-migration-gate.md)

这份门禁的作用是把“研究原型通过”和“正式武器可以上线”分开。它不会创建新的 `EquipmentDefinition`、收藏 ID、存档字段或玩家可见武器。

## 2. 五项门禁

每个首发候选都必须同时通过以下五项：

| 门禁 | 要求 | 当前判定 |
|---|---|---|
| 正式 Definition | 地面/空中动作来自正式 Equipment/Action Registry，并由权威调优提供数值 | 3 把生产基线通过，3 把研究候选阻塞 |
| 正式动作状态 | 具备正式动作身份、前摇、有效、收招、冷却及冲突/取消规则 | 生产基线通过，研究候选仍只有原型时序 |
| 正式回放 | 有候选专属 MatchReplay fixture、checkpoint 和最终 hash | 六把均阻塞 |
| 地图后果 | 在 KZ 灰盒中出现可解释的命中安全/击落或路线转移差异 | 六把均已有研究证据 |
| 反馈表现 | 权威反馈事件带有正式动作来源，并接入表现链 | 生产基线通过，研究候选阻塞 |

“地图后果已通过”只表示研究探针已经看到武器差异会改变路线结果，不表示平衡、多人拥挤、复活重入或真人可读性已经完成。

## 4. 研究证据如何被使用

### 直线压制

继续复用单一攻击线原型，先接入正式动作状态和候选专属 Replay。不能因为它出手快就直接变成生产远程武器。

### 读招反制

必须把承诺、提前取消、有效窗口和到期处理从独立整数 tick 原型转成正式动作状态，再验证玩家能否读懂高回报对应的长承诺。

### 绕后

必须把目标朝向判定、侧后方有效范围和分叉路线后果接入正式动作与 Replay；固定“目标背向攻击者”的探针不能代替目标主动转身。

## 5. 下一批实现顺序

1. 先为直线压制建立正式 Action/Equipment 迁移草案，不修改生产注册表。
2. 为直线压制生成候选专属固定输入 Replay，核对事件序列、checkpoint 和最终 hash。
3. 将同一 Replay/地图后果合同复用于读招反制，再处理承诺状态。
4. 最后处理绕后，补上主动转身和分叉路线的回应脚本。
5. 只有五项门禁全部通过，才允许单独评审是否进入正式 `STAGE4_*` 内容；本门禁不自动晋级。

## 6. 当前明确结论

本轮已经完成“迁移前的证据收敛”，没有完成“六把武器生产化”。下一步最小结构性改动是直线压制的正式 Action 状态和候选专属 Replay，不扩张角色、按键、界面或收藏系统。

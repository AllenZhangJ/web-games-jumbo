# ADR-098：KZ 分叉武器研究必须覆盖入口、转折和出口

- 状态：已接受，已接入研究工具链
- 日期：2026-07-28
- 范围：四条 KZ 分叉灰盒与研究武器后果探针；不进入生产 MapRegistry、多人网络合同或最终地图资产

## 背景

此前每条 KZ 分叉只在一个中段战斗面上运行武器探针。它能证明路线角色会改变击落、转移和空放，但不能证明武器在玩家刚进入路线、处理转折和接近出口时是否有不同答案。CS1.6 式跳跃地图的学习价值来自连续路线决策，单点攻击不足以支撑“熟悉地图 × 熟悉武器”的长期循环。

## 决策

1. 每条分叉固定选取三个研究攻击点：`entry` 为第一面，`turn` 为路线中点，`exit` 为最后一面。
2. 每个攻击点继续复用同一组五种战斗语言和三种固定回应 `hold / step-out / jump`，不新增按键或直接写位置。
3. 结果同时保留攻击点、surface ID、waypoint index、命中、击落、支撑面转移、路线失误和空放，避免只汇总成一条分叉标签。
4. 分叉总览仍保留，攻击点摘要作为独立维度输出；研究探针不等于真人选择、真实画布可见性或多人拥挤验证。

## 被考虑的替代方案

### 继续只测中段一个攻击面

- 放弃原因：无法观察入口接近、转折暴露和出口冲刺阶段的武器价值变化，不能验证路线熟练的阶段性。

### 每个分叉手工挑不同攻击位置

- 放弃原因：不同分叉之间无法比较，且容易把研究者预期写成结果；固定入口/中点/出口规则更容易复现。

### 直接把攻击点做成最终地图机关

- 放弃原因：当前只有研究几何和固定回应，尚无真实画布、多人拥挤、网络同步或真人路线选择证据，不能提前扩大生产地图边界。

## 后果

- 当前探针规模从 60 扩展到 180 个，并能按分叉和攻击点比较。
- 同一分叉不同阶段可以出现不同的击落/转移组合，支持后续把武器熟练和地图熟练绑定到具体路线阶段。
- 探针运行成本增加，但仍保持确定性、无渲染和共享 Rule/Action/Physics；后续仍需真实画布截图、2–4 人拥挤和真人路线选择。

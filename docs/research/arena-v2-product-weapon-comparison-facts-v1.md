# Arena V2 Product 武器数值差异事实原型结果 V1

## 状态

- 状态：已接入 Product UI 场景模型与 Web 武器卡；定向模型、网页语义和类型检查通过
- 日期：2026-07-28
- 范围：将热血英豪研究提炼出的“核心动词 + 数值取舍 + 失败成本”压缩为首见差异事实
- 实现：`packages/arena-product-presentation/src/product-ui-scene-model.ts`、`src/entry/web-product-ui-surface.ts`、`src/product-styles.css`
- 测试：`packages/arena-product-presentation/test/product-presentation-boundaries.test.ts`、`tests/entry-web-product-ui-surface.test.ts`
- 生产边界：不新增权威战斗字段，不修改 MatchCore，不注册研究武器，不计算综合评分

## 1. 为什么需要这一层

热血英豪的武器价值来自一组关系：攻击上下文、命中结果、地图位置、前后摇和反制。官方说明中，魔血镰刃同时强调中距离大范围魔轮、脚下陷阱、跑动蓄力等级和地面突起；白金双枪区分点射、空中射击、水平弹幕、扇形扫射和资源限制；猛犸石斧则把延迟落点、蓄力重击、滚动物体、墙面反弹和公共危险放在同一件武器里。它们都说明“武器不同”不能只靠名称、外观或一个伤害数字。

当前 Product 已经有同源的 9 项主数值、2 项行为数值和地面/空中上下文。差异事实原型解决的是另一个问题：让玩家不用先扫描完整矩阵，就能看到一项优势和一项代价，然后再用精确数值核对。

## 2. 事实生成合同

| 规则 | 当前实现 |
|---|---|
| 来源 | `ProductUiSceneModel` 已生成的横向主数值比较行 |
| 差异条件 | 只有跨武器唯一最大值或唯一最小值才生成事实 |
| 并列处理 | 并列极值不生成“最强/最弱”，避免伪造差异 |
| 每卡数量 | 最多两条，优先一条优势和一条代价 |
| 数值保真 | 事实保留 `statId`、原始 `value`、`unit`、`precision` |
| 方向语义 | 出手/收招/再次使用和自身风险使用独立的有利方向 |
| 禁止项 | 不计算综合评分，不改变动作调优，不从文案手填结论 |

事实不是新的平衡字段，而是同源数值的阅读入口。调优值改变后，事实随比较行重新派生。

## 3. 当前三把生产武器读出

当前权威 Product 投影中的代表差异：

| 武器 | 首见优势事实 | 首见代价事实 | 对应战斗语言 |
|---|---|---|---|
| 引力锁链 | 射程最远 `5.00格` | 击飞最弱 `1.19格` | 拉位与远程牵制 |
| 重锤 | 击飞最强 `2.68格` | 收招最长 `0.40秒` | 推离与边缘击飞 |
| 冲锋盾 | 出手最快 `0.08秒` | 射程最近 `1.60格` | 冲入与自身换位 |

表格中的事实不是综合评价：锁链仍然可能在宽平台和窄路入口更有价值，重锤仍然需要承担长收招，冲锋盾仍然要处理高自身位移风险。玩家看到的是可比较的选择依据，而不是武器排名。

## 4. 代码与表现验证

- 场景模型从比较行生成 `comparisonFacts`，每张卡最多两条；
- 两件测试武器验证唯一极值、优势/代价方向和原始数值保留；
- Web Product 卡片将事实显示为带数值的语义标签，并通过 `aria-label` 暴露完整含义；
- 当前 Web 语义测试验证锁链显示“射程最远 5.00格”和“覆盖最宽 8.35格”；
- Canvas Product 仍绘制同源公开比较表，不另造一套事实或数值来源。

## 5. 对热血英豪研究的直接贡献

这层实现把逐件研究中的五段学习链进一步压缩到玩家首见读出：

```text
核心动词 → 数值优势 → 数值代价 → 地图用途 → 反制
```

例如“推离”不是只写在卡片文案里，而是由横向击飞和收招共同支撑；“拉位”不是只写远距离，而是同时保留覆盖、击飞和方向容错的差异；“冲入”不是单纯更快，而是把更短距离和更高自身风险一起展示。

## 6. 未关闭问题

- 当前事实词汇仍是中文 Product 展示，其他语言需要消息目录化；
- 当前只从主数值生成事实，地面/空中上下文、有效窗口和延迟信号仍由比较表或独立研究表承担；
- 唯一极值事实仍需真人验证，不能用自动化通过替代 10 秒理解率；
- 研究候选的六件武器仍不进入默认 Product，必须先通过 Definition、Replay、地图后果、反馈和真人迁移门禁；
- 差异事实只解决首见信息，不等于完成 CS KZ 地图、弹壳特攻队局外页面或 200 小时留存验证。

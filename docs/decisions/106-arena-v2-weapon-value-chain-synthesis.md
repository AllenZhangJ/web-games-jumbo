# ADR-106：武器必须以动作链和地图后果形成独立价值

## Status

Accepted（Arena V2 研究与生产边界）

## Date

2026-07-28

## Context

热血英豪的武器差异来自招式时机、距离、方向、命中结果、地图位置和失败成本的组合。若 Arena 只用模型、武器名称或一句“近战/远程”区分武器，玩家无法理解为什么要熟悉不同武器，也无法形成 200 小时收集目标所需要的行为记忆。

当前项目已经有六件逐动作研究案例、研究 Definition 和公共数值矩阵，但它们需要一份跨案例的统一判断标准，避免后续新增武器时又回到外观或功能标签。

## Decision

所有研究武器和未来生产武器都必须通过六项价值链审计：

1. 动作身份；
2. 承诺时间；
3. 空间条件；
4. 命中后果；
5. 失败成本；
6. 反制与反馈。

武器概览至少展示公共数值轴及方向语义：有效距离、覆盖宽度、出手、收招、横向击飞、垂直控制、控制时间、自身位移风险、再次使用时间，并在需要时展示地面/空中上下文、有效攻击窗口和方向容错。延迟、预警、持续区域和原作资源字段只有在权威运行时与真人可读性证据齐全后才能进入生产展示。

六件逐动作案例的研究结论收敛见[热血英豪武器研究综合与设计收敛 V1](../gameplay/arena-v2-hot-blooded-weapon-design-synthesis.md)。该综合不增加角色、按键或默认生产武器。

## Alternatives Considered

### 只按武器类型区分

例如近战、远程、重武器。拒绝：同一类型内部的距离、时机、地图后果和失败成本仍可能完全不同，无法支持玩家长期熟悉。

### 只显示综合评分

拒绝：综合评分隐藏取舍，玩家无法知道“高覆盖”是否伴随更长收招，也无法把数字用于地图选择。

### 直接复制原作技能和资源系统

拒绝：原作职业协同、MP、自动瞄准、格挡/架招、无敌、多段连招和公共危险会扩大操作与平衡维度，违背 Arena 的六角色、基础操作快速入门和武器/地图主导目标。

## Consequences

- 新武器必须先形成可解释的行为链，再进入 Definition 和数值投影；
- Product 概览可以让玩家看见数值差异，而不是只看外观或文案；
- 研究候选与生产武器边界更清晰，复杂原作能力可以按最小版本拆分；
- 后续真机、真人和生产迁移仍是独立门禁，本文不把研究证据当成已上线结论。

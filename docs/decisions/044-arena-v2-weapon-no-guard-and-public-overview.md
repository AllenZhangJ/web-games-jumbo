# ADR-044：Arena V2 武器不引入格挡，并建立公开数值概览

## 状态

Proposed（V2 方向已确认，权威层迁移待单独批次）

## 日期

2026-07-27

## 背景

用户已经明确：本项目不做格挡系统。此前的冲锋盾原型仍通过 `front-guard` 取消锁链等效果，导致代码行为与 V2 方向不一致，也让武器差异容易退化为“防御按钮”。同时，武器的差异需要在局外界面被玩家看懂，不能只存在于动作实现和表现资源中。

## 决策

1. V2 的冲锋盾目标是只保留冲撞、目标轻度击飞和自身位移，不再注册 `front-guard` 效果。
2. V2 的冲锋盾目标类型是 `equipment-attack`，定位为“突进与换位”，而不是防御动作。
3. 在 V1 基线未完成独立 Replay/hash 迁移前，不直接改写当前 Stage4 权威动作；Core 层的通用 `front-guard` 先保留，作为历史内容兼容能力。
4. 武器概览通过表现层投影展示当前权威战斗调优中的有效距离、前摇、收招、横向作用、纵向控制、硬直、自身位移和冷却。界面显示精确数值、单位和相对条形图。
5. 概览不是新的权威配置，不能在 UI 中写入另一套平衡数值；数值必须由动作调优投影生成。

## 结果

- V2 迁移完成后，冲锋盾的反制关系回到站位、躲避和时机，武器功能更容易与热血英豪研究提取的“距离—位置—风险”语法对齐。
- 公开概览让玩家可以直接比较武器，而不需要先理解动画或源码。
- 保留 V1 Core 通用 guard 可以避免在当前历史迁移批次中扩大删除范围，但后续 V2 tuning schema 应移除未使用的 guard 字段。

## 验收证据

- 当前 V1 Stage4 与其 Replay/规则测试保持不变；
- `ProductContentPresentationDefinition.overview` 验证数值字段、单位、方向和精度；
- Product UI 主页显示三把现有武器的公开数值卡片。
- 三把武器的地面/空中动作已通过同一权威规则层完成无渲染对比，证据见[武器上下文无渲染原型结果](../research/arena-v2-weapon-prototype-results-v1.md)。

## 后续

- 研究完成后，将把“动作时序、命中结果、适用地形、风险和反制”补入武器详情页；
- 当前静态对比已证明差异存在，但不替代窄路/边缘地图与真人可读性验证；
- V2 权威 tuning 正式分支建立后，删除未使用的 guard 字段和历史兼容路径，单独记录 Replay/hash 迁移证据；在此之前不更新 V1 固定回放和实验哈希。

# Arena V2 武器可读性与长期留存验证计划 V1

## 文档状态

- 状态：研究合同初稿，尚无真人样本，不得标记为通过
- 日期：2026-07-27
- 目的：验证“3 分钟掌握基础操作、武器和地图驱动长期学习、约 200 小时完成收集”是否成立
- 适用范围：武器概览、1v1、竞速 KZ 地图、生存模式和局外下一目标

## 为什么需要单独验证

当前已经有三类工程证据：

1. Rule/Physics 原型证明不同武器语言会产生不同命中、击落和路线转移结果；
2. Web DOM/Canvas 原型证明玩家可以看到距离、覆盖宽度、前摇、击飞、垂直控制和自身风险等公开数值；
3. 局外信息原型证明 11 个信息入口、关键点击预算和单一下一目标可以写成合同。

这些证据仍不能回答三个真人问题：

- 新玩家是否能在 3 分钟内完成基础移动、跳跃和一次武器使用；
- 玩家是否真的能从概览读出两把武器的数值差异，并把数值差异转成路线选择；
- 收藏、地图熟悉和模式记录是否让玩家在 30/60/120/200 小时仍有主动目标。

本计划只定义测量方式和候选门槛，不生成虚构结果。现有 `arena-human-match-study` 主要验证对手公平性和自然难度，本计划的解释率、数值阅读和长期目标需要作为独立任务记录，不能从胜率推断出来。

## 一、3 分钟基础操作任务

### 任务序列

| 任务 | 玩家必须完成的行为 | 记录指标 |
| --- | --- | --- |
| 移动 | 沿指定方向走到安全标记 | 首次成功 tick、误输入次数 |
| 跳跃 | 完成一次地面跳和一次空中跳 | 首次成功 tick、是否读懂跳跃边界 |
| 基础攻击 | 在地面对目标完成一次命中 | 首次成功 tick、挥空后是否重试 |
| 上下文攻击 | 在空中完成一次对应动作 | 是否知道同一攻击键会随状态变化 |
| 基础反制 | 看到公开前摇后用移动或跳跃避开 | 是否能说出失败原因 |

### 候选通过条件

这些是进入真人研究前预注册的候选门槛，不是已有结果：

- 参与者在 180 秒内完成全部基础任务的比例至少 80%；
- 不依赖研究员口头解释完成的比例至少 70%；
- 完成后能用自己的话说出“移动、跳跃、攻击、空中攻击”的区别，解释正确率至少 80%。

若玩家完成任务但无法解释原因，只能算操作通过，不能算学习通过。

## 二、武器概览数值解释任务

### 固定任务

每位参与者看到两到三把武器的同屏比较矩阵，在不进入对局的情况下完成：

1. 指出有效距离最高的武器；
2. 指出覆盖宽度最高的武器；
3. 指出自身位移风险最高的武器；
4. 选择更适合窄路边缘的武器，并说明理由；
5. 观察地面/空中上下文，指出同一把武器的一个数值变化。

### 必须记录

- 首次看到比较矩阵到提交答案的时间；
- 每项答案是否正确；
- 是否能解释“越低越有利”和“越高风险”的方向语义；
- 是否把覆盖宽度误解为命中率，或把自身位移误解为攻击收益；
- 从武器概览进入对局后，第一次主动使用的武器和地图位置。

### 候选通过条件

- 10 秒内完成三项直接数值比较的比例至少 80%；
- 风险方向解释正确率至少 90%；
- 地面/空中上下文差异复述正确率至少 80%；
- 选择武器的理由至少包含一个数值轴和一个地图空间，而不是只说外观或名称。

如果玩家答对数字但不能把数字用于地图选择，只算信息读取通过，不算玩法理解通过。

## 三、KZ 地图与战斗反馈任务

KZ 灰盒使用六段固定空间：平台起点、断层恢复、楼梯攀爬、迷宫、窄路和走钢丝。每次任务只改变一个变量：武器语言、路线段或回应方式。

记录：

- 玩家第一次失败所在段落；
- 玩家是否能指出“命中、击退、掉落、路线转移”中的主要原因；
- 看到直线压制、封路、延迟重击预警后是否选择移动、跳跃或等待；
- 复活后是否回到正确恢复段，而不是把失败归因成随机或输入失灵；
- 竞速是否仍然以到达终点为目标，生存是否没有被误解为竞速。

当前 54 个 KZ×武器语言探针只提供规则基线，不能代替上述真人记录。

## 四、200 小时长期目标记录

200 小时不以“重复游玩时间”单独计入，而以可验证的熟悉和收集里程碑组成：

| 里程碑 | 必须看到的行为证据 |
| --- | --- |
| 30 分钟 | 能完成基础操作，并主动比较两把武器 |
| 1 小时 | 至少完成一把武器的地面/空中上下文记录 |
| 10 小时 | 主动在两种地图空间更换武器，而不是固定使用第一把 |
| 30 小时 | 开始完成武器×地图或武器×模式交叉挑战 |
| 60 小时 | 能解释至少三种战斗语言的反制方式 |
| 120 小时 | 有明确未完成的武器、地图段落和模式记录目标 |
| 200 小时 | 完成预注册的武器收藏和核心交叉挑战，而不是只累计对局时长 |

每个里程碑记录：首次发现时间、完成时间、重复进入次数、目标点击、武器上下文完成率、地图/模式交叉使用率和主动目标文本。重复掉落必须有收集进度、上下文熟悉或交叉挑战价值，否则不计为有效长期内容。

## 五、数据与边界

- 研究记录必须绑定候选构建、武器/地图定义版本和回放身份；
- 不收集真实姓名、聊天或未经同意的社交信息；
- 研究员不得在任务中解释武器答案，解释只能在任务结束后提供；
- 自动化原型、Bot 胜率和桌面浏览器截图不能替代真人解释率；
- 没有达到样本量、分母或设备覆盖要求时，结果状态只能是 `incomplete`，不能写成“已验证”。

## 当前状态

已具备：

- 公开数值比较矩阵、覆盖宽度和地面/空中上下文；
- 六段 KZ 灰盒与三种候选战斗语言的 54 个固定回应探针；
- 11 个局外信息入口、单一下一目标和 200 小时容量预算；
- 现有真人研究工作台、Replay 验证和构建绑定基础。

尚未具备：

- 真实新手 3 分钟任务样本；
- 武器数值解释率和地图归因样本；
- 30/60/120/200 小时纵向留存样本；
- 目标手机和小游戏运行环境上的实际字号、触控和反馈记录。

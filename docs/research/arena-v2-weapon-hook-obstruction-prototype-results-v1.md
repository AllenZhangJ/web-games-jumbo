# Arena V2 血影钩刃障碍阻挡原型结果 V1

## 状态

- 状态：研究工具链原型，已通过确定性测试
- 日期：2026-07-28
- 范围：只验证钩刃拉位路径是否被二维实体障碍切断
- 不代表：正式武器、最终物理、生产地图、真人可读性或多人网络结果

## 目的

血影钩刃官方说明明确指出，钩刃招式会沿水平方向把目标拉到面前，受到物理阻碍时可能失效。[血影钩刃官方说明](https://bfo.web.sdo.com/web4/introduce/prop_explanation.asp?id=1109)

本原型只回答一个窄问题：在同样的拉位距离下，无遮挡、柱体阻挡、侧向错开和柱体边角四种路线是否得到不同结果。它使用固定点和矩形障碍进行线段相交判断，不接入生产 MatchCore、武器 Registry、渲染或地图资产。

## 固定探针结果

| 场景 | 障碍检测 | 尝试拉位 | 实际水平位移 | 结果 |
| --- | ---: | ---: | ---: | --- |
| clear-line | 否 | 1.50 | 1.50 | 拉位成立 |
| pillar-blocks | 是 | 1.50 | 0.00 | 拉位被阻挡 |
| offset-route | 否 | 1.50 | 1.50 | 拉位成立 |
| near-corner | 是 | 1.50 | 0.00 | 拉位被阻挡 |

固定结果由 `packages/arena-v1-experiment/src/arena-v2-weapon-hook-obstruction-prototype.ts` 产生，并由同名测试重复运行确认。

## 结论

1. “拉位距离”与“路径是否依赖障碍”是两个不同维度，不能在概览里只显示一个控制强度。
2. 玩家反馈至少需要区分“命中但被障碍切断”和“命中并成功拉近”，否则玩家无法归因失败。
3. 当前公共数值轴尚未把障碍依赖作为正式主轴；它暂时保持研究状态，不把研究探针伪装成生产武器属性。
4. 下一轮应把同一探针接入真实 Arena 地图表面、目标主动转身和复活重新进入路线，再决定是否新增“障碍依赖/路径可阻挡”公开字段。

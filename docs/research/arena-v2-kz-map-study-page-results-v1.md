# Arena V2：KZ 路线真实画布研究页结果 V1

状态：研究页已接入，桌面与窄屏本地浏览器验证通过；真实手机、2–4 人和真人路线理解仍待验证（2026-07-28）  
用途：验证 KZ 路线合同在真实 Canvas 中是否能同时表达主路线、分叉、模式职责、攻击点和来源迁移边界。页面只属于开发/测试工具链。

## 1. 页面范围

研究页入口：`kz-map-study.html`。它不进入生产 `index.html`，不写入生产 `MapDefinition`，不复制第三方地图资源。

页面直接消费：

- `createArenaV2JumpRoutePrototype()` 的六段路线、surface、anchor 和分叉 waypoint；
- `runArenaV2JumpRoutePrototype()` 的固定输入路线可达结果；
- `runArenaV2KzBranchWeaponConsequencePrototype()` 的分叉攻击点摘要；
- `ARENA_V2_KZ_MAP_RESEARCH_CATALOG` 的外部来源事实与 Arena 迁移结论。

## 2. 画布验证的交互合同

| 交互 | 可观察对象 | 当前结果 |
| --- | --- | --- |
| 竞速/生存切换 | 终点是否只在竞速生效，生存是否保留同一空间 | 可切换，生存标题显示“终点已移除” |
| 快线/恢复线切换 | 分叉路线的时间/暴露交换 | 可切换，迷宫高位恢复线显示 68 tick / 5 tick 暴露 |
| 六段按钮或画布点击 | 当前段落、六维难度、回应和恢复 | 六段均可选，窄路战斗暴露显示 4/4 |
| 攻击点按钮 | 入口、转折、出口的攻击位置 | 可循环标记；分叉段同时显示探针摘要 |
| 来源卡 | 外部事实、Arena 迁移、不复制边界 | 随段落切换更新，来源链接保留 |

画布的攻击摘要使用真实研究探针结果。例如迷宫恢复线入口显示 `15/15 命中、12 次击落、3 次落点转移`；这只是当前固定探针的规则层结果，不是最终平衡数值。

本地地址：`http://127.0.0.1:5175/kz-map-study.html`

| 视口 | 页面宽度 | 页面滚动宽度 | 画布 CSS 宽度 | 结果 |
| ---: | ---: | ---: | ---: | --- |
| 1280×720 | 1280 | 1280 | 约 822 | 桌面页面无横向溢出；画布、六段路线和检查器可见 |
| 390×844 | 390 | 390 | 338 | 窄屏页面无横向溢出；六个段落按钮变为两列 |

交互复核：

- 生存模式按钮状态为 `pressed=true`，文案变为“终点已移除”；
- 选择迷宫 + 恢复线后，画布显示高位恢复线，检查器显示 `路线选择段`；
- 点击攻击点后，检查器显示 `入口·已标记` 和固定探针摘要；
- 窄屏选择窄路后，检查器显示 `战斗压力段`，页面宽度仍为 390，滚动宽度仍为 390。

## 4. 本页真正证明了什么

1. 六段路线可以在同一张真实 Canvas 中被命名和区分；
2. 同一套空间合同可以切换竞速终点与生存循环职责；
3. 分叉路线的时间/暴露交换可以与段落、模式和攻击点放在同一观察面；
4. 武器攻击点可以沿路线显示，而不是只存在于测试输出；
5. 外部地图事实和 Arena 迁移结论可以在页面上明确分栏。

## 5. 仍未证明的事项

- 真实手机的摄像机跟随、纵向可见范围和触控命中率；
- 2–4 名玩家同时占据窄路、迷宫和走钢丝时的可读性；
- 真人是否能在 3 分钟内理解方向 + 跳跃，以及能否说出失败原因；
- 武器命中后玩家是否认为掉落来自攻击、路线失误还是镜头问题；
- 最终地图几何、资产授权、网络同步和生产性能。

因此本页结果只把 KZ 研究从“规则和灰盒”推进到“真实画布可观察”，不能写成地图已完成或竞速模式已发布。

## 6. 研究来源

- [KZ-Rush 地图难度标准](https://kz-rush.com/en/article/map-difficulty-criterias)：按 longjump、strafing、连续节奏和难度档位拆分能力。
- [CS1.6 KZ 入门指南](https://steamcommunity.com/sharedfiles/filedetails/?id=3272385460)：说明 longjump、bunnyhop、strafing、地图难度和练习路径。
- [Kreedz Climbing Workshop](https://steamcommunity.com/app/626680/workshop/)：观察移动类型标签、课程和长跳练习的社区组织方式。
- [bkz_goldbhop 记录](https://motd.kz-rush.ru/en/maps/cs16/bkz_goldbhop)：记录难度、路线长度、普通检查点、金检查点和完成时间的关系。

# 深研武器概览适配层原型 V1

## 状态

- 状态：研究工具链原型通过
- 日期：2026-07-28
- 范围：魔血镰刃、真·哈迪斯钩镰、白金双枪、血影钩刃、幻虎巨拳五件逐动作深研案例
- 生产影响：不新增默认武器、不修改 Content Registry、不改变现有玩家界面

## 为什么补这一层

当前生产武器概览已经能够从权威 `Definition` 投影 9 个主数值轴、2 个行为轴和地面/空中上下文；但五件逐动作深研案例只有官方事实、设计推导、反制、失败成本和数值审计，还没有经过候选 `Definition` 的真实数值测量。

如果直接把案例写入玩家数值卡，研究推断会被误读为已经平衡的数值。因此本原型只负责把“研究结论”和“还必须测量什么”接到同一份结构化读出，不填假数值。

## 原型输出

`createArenaV2WeaponCaseStudyOverview()` 为五件案例生成研究行，每行包含：

- 核心动词、战斗主张、地面/跑动/空中等上下文；
- 必须公开的公共数值轴；
- 每个数值轴的 `must-measure` 或 `research-only` 状态、原因和玩家含义；
- 地图关系信号和动作级反制集合；
- 明确的 `numericReadout: not-yet-available`，以及“未连接权威数值投影”的原因。

`must-measure` 不是“已经测出”，而是说明该轴必须进入后续候选 `Definition` 与边界测试；`research-only` 说明当前还不能承诺为玩家可读数值，例如预警、持续状态或障碍依赖。

血影钩刃的障碍阻挡、方向分支和预警轴会出现在轴审计中，但不会被伪装成现有 9 个主比较轴。障碍依赖仍需接入真实地图表面、目标主动转身、空中高度和复活重新进入路线后，才有资格讨论是否新增玩家可读字段。

## 与生产 UI 的边界

生产链路仍是 `Definition → product-session-view-model → WebProductUiSurface`，并且现有 UI 已按通用数组渲染数值、行为和上下文。此次新增的是 `arena-v1-experiment` 研究适配层，不被默认生产内容组合调用；因此它只能帮助研究人员收敛测量任务，不能让未通过迁移门禁的武器出现在正式玩家界面。

## 下一步

1. 从五件案例中选一件，建立与现有 `ActionDefinition` 相同格式的最小候选 Definition；
2. 对其地面/空中动作测出主 9 轴和行为 2 轴，而不是凭官方原作数值换算；
3. 把测量结果接入既有研究武器概览矩阵，再进行真人首见时间、命中归因和反制可读性测试；
4. 只有通过候选 Definition、Replay、地图后果、反馈表现和设备/真人门禁，才评估生产迁移。

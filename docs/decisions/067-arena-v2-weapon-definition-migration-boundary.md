# ADR-067：武器概览数值必须从权威 Definition 投影

- 状态：accepted
- 日期：2026-07-28
- 范围：Arena V2 武器 Definition、公开数值和表现层边界

## 背景

用户需要在武器概览中直接看懂不同武器的数值差异。当前三把生产武器的 `ActionDefinition` 和权威调优已经包含距离、时序、击退、控制、自身位移和地面/空中目标关系；表现层也已经显示这些数值。如果后续研究候选在页面层另写数值，武器卡、对局反馈和权威规则就会逐渐分叉。

同时，首发六种战斗语言中有三种尚无生产 Definition。它们需要明确记录结构缺口，不能只凭文案或外观进入武器概览。

## 决策

固定一份“权威字段 → 玩家数值”的投影合同：

- 主概览使用 9 个数值轴；
- 行为补充使用有效攻击窗口和方向容错 2 个轴；
- 地面/空中上下文使用 6 个数值轴；
- 直接字段从 `ARENA_GAMEPLAY_V2_TUNING` 和 `ActionDefinition` 读取；
- 覆盖宽度、控制时间和方向容错等派生数值使用固定公式；
- UI 只消费只读投影，不参与命中、拾取、随机或胜负判断。

研究候选在审计中分为 `needs-definition`，并且必须先完成权威动作、目标策略、命中结果和公开数值，再进入生产武器目录。

## 影响

- 当前三把生产武器可以继续沿用现有调优，但后续重构应优先消除重复公式，而不是重新设计一套页面数值。
- 直线压制、读招反制、绕后的迁移需要新增 Rule/Core 能力，不能仅新增展示字段。
- 武器概览的可读性可以直接与权威调优做一致性测试，降低“看起来不同、实际规则相同”的风险。
- 延迟和预警仍是研究专用字段；封路和延迟重击不能绕过本 ADR 提前进入首发。

## 后续验收

每个新增武器必须同时提交 Definition、权威投影、概览快照、对局命中反馈和确定性测试。若某个玩家可见数值无法追溯到权威字段或固定派生公式，候选状态保持 `needs-definition`。

# Arena V2 热血英豪武器研究 V1

## 文档状态

- 状态：第一轮研究，待原型验证
- 日期：2026-07-27
- 研究对象：新热血英豪官方武器说明与官方新手指南
- 研究边界：提炼对战规律，不复制名称、动作、数值、美术或输入组合

## 先给结论

热血英豪的武器差异不是“近战、远程、伤害高低”这么简单。它的武器通常同时承担四种职责：

1. 建立威胁距离；
2. 命中后改变位置或状态；
3. 在地面、空中、奔跑、侧身或边缘形成不同价值；
4. 用前摇、资源、方向、收招和失误暴露形成反制窗口。

官方指南明确把投掷列为快速攻击，把远程武器与瞄准、技巧属性和拉开距离关联起来；同时把错身、跑位、跳位、诱敌和地图深渊视为高级对战的一部分。这说明武器必须与移动和地图共同设计，而不是单独做成“技能按钮”。

## 官方指南提炼出的通用规律

### 1. 同一件武器不是一个动作

武器通常有基础动作、奔跑动作、空中动作、投掷动作、反击或必杀动作。它们不是简单的招式数量，而是对应不同的空间上下文：

```text
接近 → 试探 → 命中 → 改变位置 → 追击或撤退
       ↘ 挥空 → 暴露风险
```

Arena 不应照搬多按键连招，但要保留“同一武器在不同空间状态下有不同用途”。本项目可以使用方向 + 跳跃 + 一个上下文动作键完成地面、空中和移动变化。

### 2. 投掷是独立的战术，不是远程换皮

官方武器篇把投掷描述为快速攻击，并强调近战武器可以通过投掷解决追击不到的问题，远程武器被近身时也可以用投掷反击。

Arena 的简化版本不需要增加拾取后专门的投掷按钮，但需要在武器定义中区分：

- 直接攻击距离；
- 投掷距离；
- 投掷速度；
- 投掷后是否失去武器或进入回收窗口；
- 投掷命中是击退、打断还是区域封锁。

### 3. 命中结果比伤害数字重要

官方武器描述大量使用“倒地、浮空、击退、痉挛、旋转、固定、破防、冻结、陷阱”等结果词。对于 Arena，应该优先把结果翻译为：

- 横向击退距离；
- 垂直击飞高度；
- 拉近/推远方向；
- 受控时间；
- 是否改变路线；
- 是否能接续下一次攻击。

### 4. 高威力必然伴随清晰代价

高威胁动作通常通过蓄力、MP 消耗、长前摇、固定方向、命中条件、使用后空档或自身位置暴露进行约束。Arena 不使用 MP，但必须使用等价的可读成本：

- 前摇更长；
- 收招更长；
- 冷却更长；
- 需要更近距离或更准确方向；
- 使用后自身位移过大；
- 空挥后更容易掉出安全路线。

### 5. 地图使同一件武器产生不同答案

钩镰、斧、炸弹、榴弹和陷阱类武器的价值都依赖边缘、墙面、狭窄路线、落点和绕行空间。武器评审必须至少在三种地形测试：

- 宽平台；
- 窄桥/走钢丝；
- 高低差或断层边缘。

## 代表性武器拆解

### A. 红魔爪：接近与连续压制

官方动作包含快速连续攻击、突刺、绕到背后、浮空、空中下切、突进和无敌旋转。

抽象为 Arena：

- 核心动词：冲入；
- 主要收益：命中后继续压迫，而不是一次性大击退；
- 地图价值：窄路和追击路线；
- 主要风险：进入对手攻击距离，连续动作被躲开后失位；
- 最小版本：短距离突进 + 中等击退 + 较短收招；
- 不迁移：多段连招、无敌旋转和复杂派生。

### B. 魔血镰刃：中距离与延迟区域

官方动作包含中距离魔轮、脚下陷阱、空中横向投射物、跑动蓄力等级和地面突起攻击。

抽象为 Arena：

- 核心动词：封路；
- 主要收益：提前制造对手不能安全经过的区域；
- 地图价值：窄路、边缘入口和固定落点；
- 主要风险：效果延迟，直接命中能力弱；
- 最小版本：向前投放一个短时危险区；
- 不迁移：自动锁定、无限叠加陷阱和复杂资源系统。

### C. 真·哈迪斯钩镰：近战转换为远程

官方动作同时包含近战斩击、反弹刀光、无敌突进、破防和浮空转换。

抽象为 Arena：

- 核心动词：勾住并转换距离；
- 主要收益：近战命中后可以把对手推入危险线；
- 地图价值：边缘和平台角落；
- 主要风险：需要进入近身，投射物方向可预测；
- 最小版本：短近战命中 + 一道直线钩击/推离；
- 不迁移：固定伤害、无敌、破防三者同时存在。

### D. 幻虎巨拳：高风险反击

官方动作包含受击反击架招、蓄力冲击、破防反击、空中击飞和闪避。

抽象为 Arena：

- 核心动词：等时机再撞击；
- 主要收益：准确读到对手攻击后获得高击飞；
- 地图价值：平台边缘和狭窄对峙；
- 主要风险：等待期间没有主动压制，预测失败后浪费窗口；
- 最小版本：短暂蓄力后强击退；
- 不迁移：真正的防御/反击系统，因为本项目不做格挡。

### E. 白金双枪：距离与覆盖

官方动作提供连续射击、空中射击、扇形扫射和资源消耗，并通过瞄准提高远程可靠性。

抽象为 Arena：

- 核心动词：保持距离；
- 主要收益：不用靠近也能逼迫对手改变路线；
- 地图价值：宽平台、长直线和高低差；
- 主要风险：近身弱、攻击方向可预测、连续使用受冷却或弹药限制；
- 最小版本：一条直线投射物 + 较低击退 + 较短射击间隔；
- 不迁移：自动跟踪和高频连续射击同时存在。

### F. 真·阿瑞斯圣剑：长近战与路线穿透

官方动作包含长距离突刺、剑气、固定后爆炸、强力爆发状态和多方向攻击。

抽象为 Arena：

- 核心动词：直线穿透；
- 主要收益：控制一条路线，让对手不能正面通过；
- 主要风险：侧向覆盖弱，错过直线目标后空档明显；
- 最小版本：长距离直线刺击 + 中高击退；
- 不迁移：全属性增加和大范围终极状态。

### G. 血刃：背后与陷阱

官方动作包含背后攻击、召唤斩击、持续伤害和大范围陷阱。

抽象为 Arena：

- 核心动词：绕后；
- 主要收益：迫使对手同时注意方向和地面危险；
- 主要风险：需要侧后方位置，正面直接交换能力不稳定；
- 最小版本：侧向命中后产生方向性击退；
- 不迁移：不可防御和背后召唤同时叠加。

### H. 雪人背包：远程投掷的层级

官方动作从普通雪球、贯穿雪球、移动投掷到扇形投掷，形成多个距离和覆盖层级。

抽象为 Arena：

- 核心动词：逼走位；
- 主要收益：用低风险投掷让对手离开安全点；
- 主要风险：单发击退弱，面对贴身压迫时不稳定；
- 最小版本：直线投射物 + 低击退 + 短冷却；
- 后续成长：增加覆盖宽度或命中稳定性，不增加更多按键。

### I. 寂寞炸酱面：命中与落点二选一

官方动作既能直接投掷爆炸，也能把物品取下作为近身武器或炸弹使用；取下后会进入重新生成等待。

抽象为 Arena：

- 核心动词：放置爆炸；
- 主要收益：命中目标或控制一个落点；
- 主要风险：使用后进入资源空档；
- 最小版本：延迟爆炸投掷 + 明确危险范围；
- 重要学习点：同一件物品可以在“立即命中”和“预先布置”之间做选择。

### J. 机甲榴弹炮：直线压制与粘地延迟

官方动作包含三枚榴弹、冲拳追击、空中粘地燃烧弹和多段擒拿爆破。

抽象为 Arena：

- 核心动词：封锁走廊；
- 主要收益：让一条路线短时间不能安全通过；
- 主要风险：需要提前判断，对移动目标的即时命中较弱；
- 最小版本：抛物线投射物，落地后短延迟爆炸；
- 不迁移：持续燃烧、刚体、抓取和多段爆破同时存在。

### K. 猛犸石斧：延迟落点与重击退

官方动作包含延迟落斧、三种蓄力攻击、滚动物体和撞墙后的追加攻击。

抽象为 Arena：

- 核心动词：预判落点；
- 主要收益：用大范围重击逼迫对手离开路线；
- 主要风险：延迟高、容易被提前离开；
- 最小版本：指定落点的延迟重击；
- 后续成长：提高覆盖或改变落点方式，不直接增加伤害。

### L. 独眼巨人战锤：重击与延迟威胁

官方动作包含强力浮空、延迟手臂锤击、锁定闪电和地面陷阱。

抽象为 Arena：

- 核心动词：重击制造二次威胁；
- 主要收益：第一次命中或预判成功后，迫使对手继续移动；
- 主要风险：重击慢、二次威胁有公开预警，熟悉者可以避开；
- 最小版本：重锤命中 + 一个公开延迟落点；
- 不迁移：自动锁定和全范围无敌。

## 对 Arena 的基础武器语言

第一批正式武器不应按“锤子、链子、枪”命名，而应先按下列战斗语言分类：

| 武器语言 | 玩家要学会的事情 | 公开数值重点 |
|---|---|---|
| 推离 | 命中后把对手送向边缘 | 距离、击退、前摇、收招 |
| 拉近/换位 | 改变双方距离 | 距离、控制时间、方向稳定性 |
| 冲入 | 用自身位移换命中机会 | 自身位移、命中范围、失位风险 |
| 直线压制 | 控制一条路线 | 射程、速度、覆盖宽度、冷却 |
| 投掷/延迟 | 预判落点和逼走位 | 投掷距离、延迟、范围、回收时间 |
| 垂直控制 | 改变高度和落点 | 浮空高度、落点控制、追击窗口 |
| 区域封锁 | 让某块地暂时不可安全通过 | 持续时间、范围、预警时间、冷却 |

## 武器概览必须展示的数值

当前项目不能只展示武器名称和外观。每件武器概览至少展示以下 7 个可比较字段：

| 字段 | 单位 | 对玩家的意义 |
|---|---|---|
| 攻击距离 | 世界单位 | 需要多近才能产生威胁 |
| 出手速度 | 秒 | 对手有多少反应时间 |
| 收招时间 | 秒 | 挥空后多久能恢复行动 |
| 横向击退 | 世界单位 | 命中后离危险边缘有多近 |
| 垂直控制 | 世界单位/冲量 | 是否能改变高度和落点 |
| 自身位移 | 世界单位 | 使用时自己承担多少位移风险 |
| 冷却时间 | 秒 | 失败后多久能再次尝试 |

概览用横向条形数值比较，详情页再展示地面动作、空中动作、核心标签、适合地图和反制提示。数值必须来自权威动作定义或经过明确绑定的 V2 武器定义，不能由 UI 手写一份容易漂移的数字。

## 第一轮原型决策

先制作三把互相差异明显的原型：

1. 锤子：短距离、高击退、慢出手、长收招；
2. 链条：长距离、低击退、强换位、中等冷却；
3. 冲锋盾：自身位移、高覆盖、低目标击退、容易失位，但不带格挡。

再从研究案例中选择三把扩展原型：

1. 直线投射物；
2. 延迟区域；
3. 垂直击飞。

## 研究结论的可信边界

- 官方资料足以证明武器存在多种空间语义、命中结果和风险设计。
- 官方资料不能直接证明每个数值的平衡质量，也不能直接移植到 Arena 的物理尺度。
- Arena 的数值必须用自己的 1v1/生存原型和回放实验验证。
- 热血英豪的防御、反击、MP、职业属性和复杂连招只作为案例，不直接进入当前版本。

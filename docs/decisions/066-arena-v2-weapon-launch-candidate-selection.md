# ADR-066：首发武器候选按六种战斗语言收敛

- 状态：accepted
- 日期：2026-07-27
- 范围：Arena V2 开发/测试工具链的首发候选筛选

## 背景

当前已经有 12 件外部参考武器、8 种 Arena 战斗语言和 3 把现有生产基线。继续按参考对象数量扩充，会让首发范围失控，也无法回答玩家为什么要选择某一把武器。另一方面，武器概览已经要求公开显示距离、出手、击退、控制、收招和行为补充数值，因此首发候选必须先满足“功能不同且数值可比较”。

公开数值轴检查的结果是：冲入、推离、换位、直线压制、读招反制和绕后已经 ready；封路和延迟重击仍依赖延迟/预警研究字段。当前生产重锤、引力锁链和冲锋盾也已经通过 ADR-065 建立显式语言映射。

## 决策

首发候选固定为六种战斗语言：

- 生产基线：冲入、推离、换位；
- 研究候选：直线压制、读招反制、绕后。

候选合同必须同时记录候选顺序、来源性质、参考对象（如有）、生产 Definition 身份（如有）、核心动词、模式适配和必需公开数值轴。候选集合必须保持三把生产基线与三把研究候选，且六种语言不能重复。

封路和延迟重击不进入首发候选集合，直到延迟时间、预警时间和对应地图后果能够进入正式玩家概览，并通过真人可读性验证。

研究候选仍然只进入实验工具链，不改变当前生产武器目录、不复制外部名称/资产/动作，不把合同状态写成“已实现”。

## 选择理由

六种语言形成由浅入深的学习路径：冲入先建立接触交换；推离建立命中反馈和边缘击落；换位建立距离与地图关系；直线压制建立远距离路线压力；读招反制建立熟悉对手节奏后的高回报；绕后建立方向观察和分叉路线决策。

这组选择覆盖不同地图空间和玩家决策，同时不新增操作按键。它也为后续 200 小时目标提供六个可重复熟悉的武器上下文，而不是用相似武器的外观差异填充收藏数量。

## 影响与后续

- 首发武器不是六个最终生产资产，而是六个功能位置；其中三个需要 Definition 迁移。
- 直线压制、读招反制、绕后必须按 Rule → Core → Bot → Presentation 的顺序迁移。
- 每个研究候选进入生产前，都必须补齐地面/空中动作、公开数值、命中反馈、空放成本、地图后果和回放测试。
- 未来增加武器时，必须先判断它是新战斗语言、现有语言的数值变体，还是仅外观变化；后两者不能伪装成新玩法。

# Arena V2 玩法框架

## 文档状态

- 状态：初稿，讨论中
- 日期：2026-07-27

## 核心循环

```text
选择角色 / 模式
  ↓
进入地图
  ↓
移动、跳跃、拾取和使用武器
  ↓
利用地形制造击飞或躲避
  ↓
完成 1v1 淘汰或生存计时
  ↓
结算奖励、收藏进度和记录
  ↓
选择下一张地图、下一把武器或再次开始
```

## 基础操作

基础操作需要在约 3 分钟内被理解：

- 方向移动；
- 跳跃与空中移动；
- 基础攻击或当前武器动作；
- 自动拾取或替换武器；
- 被击飞后尝试回到安全地形。

最终输入映射仍需通过触控盲测冻结。规则层继续使用统一的 `InputFrame`，表现层不得直接决定命中、拾取、击飞或胜负。

## 1v1 规则方向

- 对局目标是将对手击出地图，而不是清空传统生命值。
- 武器、地形、站位和时机共同决定淘汰。
- 需要保留明确的前摇、命中窗口、收招和失误风险。
- 玩家必须能看懂攻击方向、命中与击退结果。
- 1v1 是武器设计的主要验证场，不先追求武器数量。

具体生命数量、单局时长、地图事件时间轴和胜负阈值在原型验证后冻结。

## 生存 1vE 规则方向

- 单人对抗不断增加压力的敌人。
- 使用跳跃/竞速地图的地形基座，但不设置终点，也不是竞速。
- 玩家可以利用地图躲避敌人，也可以利用武器击飞敌人。
- 敌人可以把玩家击飞出地图。
- 第一次掉落后复活，第二次掉落后结束本局。
- 武器随生存时间或轮次提高本局临时强度。

完整规则见 [V2 生存 1vE 规则](arena-v2-survival-mode.md)。

## 武器与地图的关系

每把武器至少需要回答：

1. 它在什么距离最有价值？
2. 它命中后把谁移动到哪里？
3. 它在边缘、窄路、高低差或断层上有什么变化？
4. 它落空后玩家承担什么风险？
5. 对手用什么简单方式躲避或反击？

如果一把武器脱离地图后只剩下数值差异，则不应进入正式武器池。

## 命中与反馈方向

命中反馈必须分成三层：

- 立即反馈：命中音效、闪白/轮廓、攻击方向、受击姿态。
- 结果反馈：击退轨迹、落点、是否接近边缘、是否掉落。
- 战术反馈：玩家能否据此决定继续追击、抢占地形或撤退。

反馈只表现权威事件，不创建命中或击退结果。后续需要用真人盲测验证“玩家能否解释自己刚刚发生了什么”。

## 不增加的系统

- 不做格挡系统。
- 不做训练场。
- 不做角色专属主动技能树。
- 不做复杂连招输入。
- 不做大量装饰收藏来替代玩法内容。
- 不把生存模式拆成竞速、闯关、跑酷竞赛等额外模式。

# Arena V2 生存 1vE 最小循环原型结果 V1

## 文档状态

- 状态：已完成无渲染循环原型；敌人实体、真实攻击碰撞和真人留存仍待验证
- 日期：2026-07-27
- 目的：验证“竞速地图基座 + 单一敌人压力 + 每 20 秒三选一武器 + 两次掉落机会”能否形成简单、可重复的局内循环
- 不代表：正式 V2 模式已经接入 MatchCore，也不代表临时武器等级和平衡数值已经冻结

## 1. 固定规则

原型入口为 `runArenaV2SurvivalLoopPrototype()`，位于 `packages/arena-v1-experiment`。它不启动 Renderer，不把敌人伪装成 1v1 玩家，也不修改永久武器 Definition。

已按用户确认的最小规则建立：

- 开局没有武器；
- 每 20 秒出现 3 把武器；
- 候选武器允许重复出现；
- `survivalLevel` 只存在于本局 Offer，随轮次增加；
- 敌人保持单一视觉/逻辑族，数量和刷新间隔随轮次增加；
- 地图使用六段跳跃路线的段落角色，玩家可以利用安全段、恢复段和选择段躲避；
- 玩家第一次被击落后复活，第二次被击落结束；
- 奖励只保留生存代币、地图熟练点和武器熟练点三类可解释结果。

## 2. 可复现结果

验证命令：

```text
npx vitest run packages/arena-v1-experiment/test/arena-v2-survival-loop-prototype.test.ts --reporter=verbose
Test File 1 passed；Test 1 passed
```

固定 seed `20260727` 下，原型运行 10 轮、200 秒后在第二次掉落结束：

| --- | ---: |
| 初始武器 | 无 |
| 供给间隔 | 20 秒 |

| 第 1 轮敌人数 | 4 |

| 第 1 轮刷新间隔 | 34 tick |
| 第 10 轮刷新间隔 | 16 tick |
| 第一次掉落 | 第 3 轮，复活 1 次 |
| 第二次掉落 | 第 10 轮，结束 |

同一把武器的临时控制作用力随轮次变强，但基础 Definition 不变：

| 武器 | 第 1 轮 | 第 10 轮 | 变化说明 |
| --- | ---: | ---: | --- |
| 重锤 | 15.0 | 25.8 | 本局临时等级 1 → 10 |

| 冲锋盾 | 7.5 | 12.9 | 本局临时等级 1 → 10 |

这些数字只是验证“轮次成长与基础差异可以分层”，不是最终平衡方案。正式版本需要根据敌人生命/击落阈值、地图宽度和玩家命中率重新校准，避免后期只剩数值碾压。

## 3. 设计结论

### 3.1 生存模式可以保持低维

重复游玩的来源收敛为四件事：熟悉地图路线、理解武器差异、应对越来越密的同类敌人、追求更高生存轮次。暂不增加敌人种类树、技能树、宠物、部件或复杂装备槽。

### 3.2 地图必须参与生存，而不是只做背景

原型每轮轮换六段地图角色，恢复段和选择段记录“使用地图躲避”的机会。正式敌人系统需要把这一字段替换为真实的敌人可达性、玩家绕行和击落结果；如果敌人增加后玩家只能站在一处安全角落，地图复用就失败。

### 3.3 奖励要服务下一局

结算页只需要回答：活了多久、用过几轮武器、地图熟练度增加多少、下一件想尝试什么。生存代币可用于解锁武器目录，地图/武器熟练点用于记录收集进度；不把生存临时等级带出局外，避免破坏 1v1 公平。

# ADR-054：KZ 段落攻击探针复用地图与武器规则

- 状态：已接受为 V2 研究原型边界，不进入生产 Arena V1
- 日期：2026-07-27
- 范围：`packages/arena-v1-experiment` 的地图×武器研究工具链

## 背景

CS1.6 KZ 研究已经形成六段自有灰盒路线，并通过固定输入证明 6/6 段存在可行路径。但“能跳过去”不等于“适合战斗”：武器击飞、攻击者位置、相邻表面和恢复段会改变同一段路线的实际风险。

如果继续用单独的宽平台、窄路或边缘样本，容易把地图段落与武器差异拆成两份互不关联的证据，无法判断生存模式是否真的能利用 KZ 地图基座进行躲避和分流。

## 决策

新增 `runArenaV2KzRouteCombatPrototype()`，对六段路线的代表表面分别运行三把基础武器的静态命中探针：

- 所有六段表面放入同一个轻量物理世界，保留相邻表面和恢复关系；
- 攻击通过现有 `ArenaRuleEngine` 的输入帧和 Action Definition 产生；
- 冲量通过现有 `PhysicsWorld` 端口应用；
- 输出命中 tick、横向冲量、实际位移、是否出界和命中后的支撑表面；
- 只作为开发/测试工具链研究，不修改生产武器、地图、存档、网络合同或玩家操作；
- 不因一次静态命中结果直接冻结正式地图宽度或武器数值。

## 被考虑的替代方案

### 继续使用孤立宽平台/窄路探针

- 优点：实现成本低、结果容易解释；
- 放弃原因：无法观察相邻表面是否提供恢复或改变落点，容易高估或低估路线段落风险。

### 直接把玩家位置移到命中后的目标点

- 优点：可以快速生成环形结果；
- 放弃原因：绕过物理、支撑表面和真实掉落，不能验证武器与地图的组合后果。

### 先制作完整敌人 AI 和最终地图

- 优点：更接近最终玩法；
- 放弃原因：在地图段落与武器基础关系尚未确认前，会把 AI、表现和数值问题混在一起，无法定位失败原因。

## 后果

正面影响：

- 18 个段落×武器组合可以在同一规则链路下比较；
- 证据明确显示同一武器的价值随表面宽度、段落角色和相邻恢复表面变化；
- 为后续移动/跳跃回应和生存敌人分流提供可复用的段落探针入口。

限制：

- 当前目标不会在命中前主动移动或跳跃，不能证明反应窗口足够；
- 攻击者只执行一次静态攻击，不能证明追击、拥挤和失位行为；
- 还缺少真人视野、窄屏读图和复活后重新进入路线的证据。
